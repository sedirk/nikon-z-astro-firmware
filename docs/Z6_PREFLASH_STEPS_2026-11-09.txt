尼康一代 Z6 / 原版 C3.80：首次候选测试步骤
日期：2026-11-09

审查结论：可进入受控的首次实机测试。此前尚无这份候选的真机安装、回退和 NEF 效果验收。
当前实验只关闭两组与邻域处理有关的控制；最终的暗电流保留、其他 RAW 校正和彩圈仍分别验证。

本包文件

  02_ROLLBACK/EG162080.BIN    原版 EG，大小相同，用于正常菜单回退
  verify.py                 只读校验工具，不复制、不格式化、不刷机
  REVIEW.md                 最后审查及证据范围
  baseline112.json           后续 NEF 分析的坐标基线

两个 BIN 的文件名相同，按所在文件夹区分。卡上一次只放其中一个。
只复制 BIN 本身到卡根目录，不把整个实验包拖进卡。
本包没有 WonderLantern 的声效、菜单或其他 core，不需要另装它们。
不要使用项目旧的 .bin.lab 诊断整包，不要改版本号或试图绕过更新拒绝提示。

一、准备
1. 确认机身是一代 Z6、目前原版 C3.80（用户本轮已确认版本和原版状态）。
2. 先在电脑上备份照片和需要保留的设置；相机保存设置文件不是固件/NVRAM 备份。
3. 使用充满且状态可靠的兼容电池；更新时确保供电和接触稳定。
4. 准备可靠的相机用卡和读卡器。备份完成后在相机内格式化测试卡，再关机取卡。
   格式化会清空卡；不要在尚有唯一照片副本的卡上操作。
5. 首次测试建议机身盖、单张模式，断开 USB、HDMI、快门线和外接附件，保持环境简单。
6. 刷入前先用当前原版补拍同条件基线：ISO1600、14位无损、全尺寸、两项降噪关闭，
   3 张 1/8000 bias、3 张 5 秒 dark。记录机身、间隔、环境和快门方式。
   已有样本可辅助，但本次紧邻拍摄更有利于识别温度差异。

二、校验本地包
在 <repo-root> 中打开 PowerShell，运行：
  .\work\re_env\Scripts\python.exe .\outputs\Z6-C380-preflash-reviewed-2026-11-09\verify.py
应返回 "ok": true。校验失败即停止使用此包。
转移到其他电脑时，也可在包内运行 python verify.py（标准 Python，无第三方依赖）。

三、先检查原版回退文件能被识别（只检查，不刷入）
1. 将 02_ROLLBACK 中的 EG162080.BIN 复制到测试卡根目录；确认根目录只有这一个固件 BIN。
2. 安全弹出并重新插入读卡器，再运行卡上回读校验：
  .\work\re_env\Scripts\python.exe .\outputs\Z6-C380-preflash-reviewed-2026-11-09\verify.py --card-root E:\ --mode rollback
   E:\ 只是示例，须换成这张卡的实际盘符；工具只读。
3. 安全弹出，关机状态下插卡，开机进入“设置菜单 → 固件版本”。
   按界面查看可更新内容；如出现最终“是/否”确认，选择“否/取消”。
   应是本机 C 固件 3.80 对应更新，而非其他组件或异常版本。
4. 没有更新入口、型号/组件异常或出现报错时，取消并记录画面，先不要尝试强制更新。
   菜单识别通过说明当前机身看得到回退文件，仍不等于故障后的恢复测试。

四、替换为候选并做首次更新
1. 退出菜单并正常关机，取卡；在电脑上移除卡根目录的原版 BIN。
   电脑中的原版回退文件和官方原文件始终保留。
2. 将 01_TEST 中的 EG162080.BIN 复制到卡根目录。
3. 安全弹出并重新插入读卡器，运行：
  .\work\re_env\Scripts\python.exe .\outputs\Z6-C380-preflash-reviewed-2026-11-09\verify.py --card-root E:\ --mode test
   "ok": true 表示包和这次卡上文件均通过；未指定 --card-root 只会检查电脑里的文件。
4. 安全弹出，关机状态下插卡。保持电源稳定，进入“设置菜单 → 固件版本 → 更新”。
   版本仍可能显示 3.80 → 3.80，这是预期；我们没有伪装版本号。
5. 确认文件、组件和电量均正常后，由你手动确认更新。
   更新开始后按屏幕指示等待，期间不关机、拔卡、拔电池或操作附件。
   如果进度似乎停住，先保持供电，记录屏幕、指示灯和经过时间；不要按一个自行猜测的超时拔电池。
6. 只有屏幕明确提示完成并要求关机后，才按提示关机、取卡。保留成功画面和时间记录。

五、最小拍摄测试与回退
1. 更新完成后，用没有固件 BIN 的拍摄卡正常开机，先检查菜单、回放和普通单张拍摄。
   相机仍显示 3.80，单看版本号不能确认补丁是否生效。
2. 先拍一张普通 NEF，确认能保存、回放、在电脑上完整解码，再拍上述 3 bias + 3 张 5 秒 dark。
   原版和候选样本分文件夹保存，不覆盖；保留原始 NEF、设置、拍摄顺序和时间。
3. 若仍能正常进入菜单但出现拍摄异常，停止增加测试负载，使用 02_ROLLBACK 的原版 EG：
   卡上只放这一份，按 --mode rollback 校验后，通过正常固件菜单回退。
4. 若候选基本拍摄正常，可在短测试结束后安排一次原版回退，并补拍同条件样本，
   完成“原版 → 候选 → 原版”对照；无需为每个曝光来回刷写。
5. 回退后也显示 3.80，以回退文件哈希、更新完成记录和复拍样本共同判断。

恢复边界
原版 EG 适用于机身仍能正常进入更新菜单的情况。我们尚未验证不开机后的救砖入口，
也没有这台机身完整 flash/NVRAM 备份。若更新失败后无法正常启动，可能需要维修或硬件编程。
原厂重试/读回检查并不提供断电自动恢复保证；本地保留固件文件也不等于已经能救砖。
原始完整官方文件仍在 firmware/original/Z_6_0380.bin，单模块常规回退优先使用本包 02_ROLLBACK。
