## 1. 核心审计结论摘要

1. **菜单切换、文件命名与 sRGB 色彩空间锁定已实机闭环**：
   - 18 张实拍 NEF（快门计数 `480719..480738`，镜头 `Viltrox AF 16/1.8 Z`，手动 `M` 档，`ISO 1600`，`f/1.8`）文件名前缀 **18/18 全部为标准 `Z61_`**（彻底消除 `Modified21` 的 `_Z61` Adobe RGB 前缀）；
   - MakerNote `ColorSpace (0x001E)` **18/18 全部为 `1 (sRGB)`**，`BlackLevel (0x003D)` 全部为 `[1008, 1008, 1008, 1008]`；
   - 证明 `PID 0x0526`（`RAM 0xC24CDEA0`）UI 门控与 `0x1014BB28` 处 `PID 0x130A = 0 (sRGB)` 有效色空间锁定在真机完全生效。
2. **前端 ISP 梳状缺码（同心彩圈根因）显著抑制**：
   - 在完全相同的曝光与编码布局下（1/8000s、ISO 1600、`packed_14bit_stride10624`）：
     - **平场对照**（直通 `Z61_5110..5112` vs 标准 `Z61_5119..5121`）：中心 R 通道 16384-bin 未归一化 `|rfft|` 在 `0.2276001 cyc/DN`（`bin 3729`）中位幅值从 **`33,437.7` 降至 `4,650.4`**（降幅 **7.2×**；单帧代表对 `5119` vs `5110` 从 **`27,241.6` 降至 `2,012.4`**，降幅 **13.5×**）；在 `[0.22, 0.24] cyc/DN` 频带峰值中位数从 **`278,369.0` 降至 `28,450.9`**（降幅 **9.8×**）；平场中心 `R/G1` 中位数比从机内白平衡预调制的 `1.0101~1.0105`（中位 `1.0103`）回归传感器原生量子效率比 `0.8985~0.9035`（中位 `0.8997`）。
     - **偏置场对照**（直通 `Z61_5102..5104` vs 标准 `Z61_5113..5115`）：`bin 3729` 中位幅值从 **`420,840.8` 降至 `34,012.9`**（降幅 **12.4×**，代表对 `5113` vs `5102` 降幅 **13.4×**）；`[0.22, 0.24]` 频带峰值中位数从 **`421,913.1` 降至 `63,311.9`**（降幅 **6.7×**）。
3. **暗场热像素保留与读出噪声统计**：
   - **偏置帧差读出噪声**（单帧折算 $\sigma = \text{estimator}(A - B)/\sqrt{2}$，全幅 `6064×4040`）：直通组 `5102 vs 5103` 中央 68.27% 分位法 **`3.5355 DN`**、IQR 法 **`3.1450 DN`**、未裁剪标准差 **`4.1133 DN`**；标准组 `5113 vs 5114`（受机内数字增益放大离散跨度影响）分别为 **`3.5355 DN`**、**`4.1934 DN`** 与 **`4.5945 DN`**；两组有效区 `0 ADU` 像素计数均为 **`0`**，`<1008 DN` 负向噪声分布完整保留。
   - **112 冻结热像素邻域钳位核验**：M22 标准模式 5s 暗场（`Z61_5116..5118`）命中原厂 `max8 + 8k` 钳位规则 **`102~107 / 112`（`91.1%~95.5%`，逐帧 `105, 102, 107 / 112`）**；而 M22 天文直通 5s 暗场（`Z61_5105..5107`）在上部连续洁净行区（`y+2 < 3633`）的 **95 个冻结点上命中率为 `0 / 95`（0%），且三帧全部 `95 / 95`（100%）超出 `+56 DN`**（中位邻域差 `+14,448 ~ +15,230 DN`，与 `Modified13` 无损压缩 5s 暗场 `Z61_5007..5009` 的 `0 / 112` 钳位、`112 / 112` 超出 `+56 DN` 完全一致）。
4. **重要发现与使用约束：`Astro RAW + 5s 未压缩 NEF` 的 16-bit LE 布局与嵌入预览覆盖异常**：
   - 15 张 1/8000s 帧及标准 5s 暗场均为标准 `42,920,960` B（`packed-14`，行距 `10,624` B），独立解包器与 LibRaw 0.22.2 在全部 `15 × 24,498,560` 个像素上 **逐像素零误差**。
   - 唯独 **`Z61_5105 / 5106 / 5107`（直通模式 + 5s 长曝光 + 未压缩记录）** 虽然 TIFF 标签仍声明 `Compression=34713, BitsPerSample=14`，实际却写出 **`48,997,120` B（`6064×4040×2`）未压缩 16-bit LE 像素流**，且机身将 3 个内嵌预览 JPEG 副本写入了该 RAW strip 内部固定偏移，覆盖了底部 **第 `3633..4000` 行**；同时导致 LibRaw/rawpy 误按 packed-14 解码出整帧伪影。
   - **用户操作规范**：在开启「直通RAW (sRGB)」拍摄 **`>= 1s` 曝光**时，请在「NEF(RAW)记录 -> NEF(RAW)压缩」中**固定使用「无损压缩（Lossless compressed）」**（`Modified13` 实拍无损压缩 5s 暗场 `Z61_5007..5009` 已验证 100% 正常解码、无任何预览覆盖）。

## 4. `Z61_5105 / 5106 / 5107` 未压缩 16-bit LE 布局与嵌入预览覆盖分析

在 `samples/11.17_modified22` 中，`Z61_5105`、`Z61_5106`、`Z61_5107`（均为 `Astro RAW + 5s`）呈现出与其余 15 张 `packed-14` 样本截然不同的底层存储结构：

1. **真实像素编码为 `16-bit little-endian`（而非 TIFF 声明的 `packed-14`）**：
   - `SubIFD2` 仍声明 `Compression = 34713`、`BitsPerSample = 14`，但 `StripByteCounts = 48,997,120 = 6064 × 4040 × 2`（其余 15 张为 `42,920,960 = 4040 × 10,624`），且 `StripOffset + StripByteCounts == filesize` 精确成立。
   - 按 `16-bit LE`（每行 `12,128` B）解析无预览覆盖洁净区：中位数 `1008~1009 DN`、相邻像元平均绝对差约 `7.6 DN`（与标准 5s 暗场 `Z61_5116` 的 `7.0 DN` 完全同阶）、最大值 `<= 16383`、`0 ADU` 计数为 **`0`**。
   - LibRaw 0.22.2 / `rawpy 0.28.0` 仅依据 `Compression=34713` + `BitsPerSample=14` 将其误当作 `packed-14` 解包，导致中位数跳变为 `3840~3856 DN`、中位数 `±50` 窗口仅 7 个码位非空、并凭空产生 `41,144 ~ 54,156` 个假零码。因此早期误用 `Z61_5105` 作为平场绘制对比图的脚本已废弃，现统一使用同条件 `packed-14` 真平场对 `Z61_5110` vs `Z61_5119`（见 `tools/generate_m22_verification_figure.py`）。
2. **RAW Strip 内部固定偏移叠加了 3 段本文件预览 JPEG 副本**：
   - 相对 `SubIFD2 StripOffset` 起点，三份文件在完全相同的 512 字节对齐相对偏移处写入了与文件头部声明预览 **SHA-256 逐字节一致** 的 3 个 JPEG 副本：
     - `+44,072,448` (`0x02A07E00` = `42,920,960 [packed-14 strip] + ceil(1,151,400 [SubIFD5] / 512) × 512`)：`SubIFD1` 大预览 JPEG 副本（约 `536~567 KB`）；
     - `+48,027,648` (`0x02DCC000`)：`MakerNote PreviewIFD` 缩略图 JPEG 副本（约 `35~40 KB`）；
     - `+48,204,288` (`0x02DF8000`)：`SubIFD3` 中预览 JPEG 副本（约 `266~311 KB`）。
   - 该行为源于当 RAW 实际按 `48,997,120` B（16-bit）写出时，预览槽位仍按 `42,920,960` B（packed-14）模板排布，从而覆盖了底部第 **`3633..4000` 行区域**（逐文件受覆盖行区间为 `3633..4000`、`3633..3996`、`3633..3998`，其余 `3672~3676 / 4040 = 90.9%~91.0%` 行像素完好）。

## 5. 已知验证边界与使用建议

- **长曝光推荐设置**：在机身开启「天文直通RAW模式 -> 直通RAW (sRGB)」进行长曝光（`>= 1s`）深空拍摄时，请将「NEF(RAW)压缩」设为 **「无损压缩（Lossless compressed）」**，即可同时获得 14-bit 完整线性暗电流保留、无损体积与主流解码器（LibRaw / PixInsight / Lightroom）100% 兼容性。
- **未外推事项声明**：
  1. `16-bit LE` + 预览覆盖现象在现有样本中仅出现于 `Astro RAW + 5s + 未压缩` 组合；固件内部触发该格式切换的精确分支条件尚未在反汇编层单独剥离修复。
  2. M 档 `60"~600"` 扩展慢门已在指令/计时器分频表层完成验证，但物理机械快门的微秒级绝对曝光精度、掉电异常恢复与天体测光绝对线性标定不在本批室内校准样本覆盖范围内。
