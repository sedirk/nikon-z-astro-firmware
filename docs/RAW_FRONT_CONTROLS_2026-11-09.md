# modified3 实拍之后：前端控制入口与单指令 LAB 副本

本轮沿固定标定和前端处理继续推进，新增一个可单独清除前端 bit11 的离线副本。它继承 modified3，在静态曝光入口仅换一条指令。已验证到原厂控制生成和寄存器写入；bit11 对应的物理校正名称、真机原本是否置位、以及彩圈响应仍是下一步定位项。副本放在 analysis/LAB，未生成安装包。

## 1. 实拍依据与本轮决定

以 [modified3 实拍报告](MODIFIED3_REAL_NEF_2026-11-09.md) 为依据：确认刷入后的 4886/4888/4889 平场和 4890–4892 暗场可完整独立解码；NEFInfo7 active=0，非中性空间系数归零，旧暗角中性化保持。112 个冻结点的旧邻域抑制关系在每张 modified3 dark 中均为 0/112，111 个强点延续，另一个低点在 modified2 已同样偏低。

平场 R/G 宽起伏 1.256→1.380、B/G 1.431→1.350 个百分点，没有整体消圈改善。用户确认设备/亮度相同，机位或对焦可能移动；1/8000 秒屏幕平场还包含光源、镜头和条带因素。本轮不把宽颜色结构直接命名为某个固件阶段的产物，也不再把后端空间标签归零作为消圈结论。

因此保留已验证暗场补丁，把新变量移到前端实际控制写入处。真正的传感器 RAW、解码后的 NEF 和模拟器配置分别记录。

## 2. 三个控制来源已经区分

全局前端 context 为 `c18fa844`，以下偏移都是十六进制。

| 来源 / 原厂指令 | 实际条件与效果 | 本轮判断 |
| --- | --- | --- |
| `100f64bc` 读取配置 `0x3d8` → static input+40 → `10179962` | 值 0/1 时 context+80=1，其它值为 0；也影响 context+23。`10179d42/46` 据此决定是否进入临时前端准备阶段。policy bit3 及四个阈值也受其影响 | 多处联动，未用作单项校正开关 |
| `100f64c8` 读取 `0x3d9` → input+41 | context+70 为 1，当输入=1，或输入=0 且 context+74 非零 / `time_numerator <= 3*s16(time_denominator)`；其它条件为 0 | 保留曝光阶段原条件 |
| `100f64b4` 读取前端源对象+259 → input+45 → `10179a8e/92` | 写入 context+5d；值1强制 policy 第2项=1，值2强制=0，其它值取选中标定记录 u16+4 | 独立覆盖 bit11 的静态读取点 |
| `10179a9c` | 静态 context+38 明确写零 | 非零时输出 `0x2006` 属于另一种上下文政策，不是本轮静态输入的天然状态 |

bit11 的已定位路径为：

```text
前端源对象+259
  → 100f64b4 / 100f64b8：static input+45
  → 10179962，10179a8e/92：context+5d
  → 1011db02：选中 CAL+55c0+index*128
  → 1011d850..1011d866：control[2] 原厂覆盖分支
  → c29a3520[2] → packet c29a34c0[0]
  → 100bccd0 → 100d8248 → 1010adf6
  → 20068500 bit11
```

`1011db02` 整个选择器已在本轮执行，包含增益分档、临时阶段、曝光分类与 ROM 索引，并非只向上传器塞入目标数值。112 次原版/modified3 执行（56 对）一致。人工非零政策记录使该位明确处于可变化状态；这些记录不是相机标定转储。

**对象身份更正：** `1013fa20..50` 确实可从其输入+a8 复制四字节到一个 owner+258；然而本轮 QEMU 中它写的是后端 owner `c3b568d0`，而 `100f64b4` 读的是前端源对象 `c236d378`，且后者先发生。不能把同偏移接成同一连续调用链。source-probe 的前缀是人为组合的字段传播夹具；前端消费者关系从 `100f6494` 开始独立成立。实验副本只改这个真实前端读取点，没有改后端 owner。

两个找到的静态调用点 `101e216c`、`101e43c0` 都把 `c236d378` 交给 `100f6290`。这是静态曝光入口，尚未按所有 JPEG/连拍/特殊模式穷尽拆分为 NEF 独占入口。

## 3. 固定标定及前端范围进一步收窄

14 字段主控制、32×4 表、2×144 表和六组前端参数块仍由原厂代码构造，未清空整个 CAL。已有 204 字节记录 `1011e58c/10122c20` 负责六组中的四组；本轮补齐另外两组的写入者：

- `1011e6ba` 选择 52 字节记录，`1011e616` 把两组各8个 u16、2个 u32 展开到 `c29a3754` 的第0/3组，并复制两个组标志。
- 记录选择包含 mode、context+84 临时状态、context+1c 分档及 +2c/+30/+14 条件。三条地址式为 `CAL+4b190+group*63700+bin*10608+subbin*364+index*52`，或 `CAL+4dacc+group*63700+bin*10608`，或 `CAL+5aa30+group*63700`。式中乘数为十进制，CAL 偏移为十六进制。维度用数值命名，未擅自认作二维光学校正。
- modified3 QEMU 静态阶段实际选中 policy `CAL+5640`、144表默认记录 `CAL+2dbd0`、第0/3组记录 `CAL+5808c`。该默认144记录沿用既有表缓存；因此单凭实拍1/8000秒不能断言已进入非默认短曝光表计算分支。
- CAL 是资源 ID38 对应的运行时标定区。模拟器内容是原有合成零数据，不据此判断真实机身值，也不把资源存储归属直接认作单机 EEPROM。

## 4. 新 LAB 副本与离线结果

配方：[z6-c380-front-bit11-off-lab.json](../patches/z6-c380-front-bit11-off-lab.json)。

实验文件：`analysis/raw-front-controls-2026-11-09/lab-module/modified3-front-bit11-off-lab.bi`（本地归档，未公开）。**仅供研究，未完成安装前审查。**

相对 modified3 唯一新增指令：

```text
100f64b4  90 f8 59 02  ldrb.w r0, [r0, #0x259]
       → 4f f0 02 00  mov.w  r0, #2
```

随后仍由原厂代码构造 context、选择记录、显式清 bit11 并上传。MOV.W 不更新条件标志。不改源对象或标定内容，不改升级/启动代码，也不改 RAW 指针。modified1/2/3 的九处修改全部继承。

文件大小33,502,842字节；相对 modified3 为 **4个代码字节 + 2个 CRC 字节**变化。SHA-256：

```text
bdf30026dc9d18b09a5ca9332369d126729d63a36013e94b8b20cf6638a4ef1b
```

已完成：

1. **56对源控制→完整选择器→上传对照。** 相比 modified3，输入仅+45、context仅+5d改变，原控制对象、记录选择、相邻阈值保持；上传结果只允许 bit11 清零。
2. **完整静态前端构造到分派入口 + 原厂上传器。** 两种临时状态、两版本共4次；每次507次 MMIO 写入。非零标定夹具中，`20068500` 从 `3fff` 变 `37ff`，其它寄存器最终值相同；1.68MB CAL 和 owner 保持。未启动真实设备，不生成图像。
3. **128次寄存器/条件标志检查。** 两版本、16种 NZCV、4种源值，栈、其它寄存器、NZCV不变，唯一参数字节写入符合预期。
4. **24步保留内存的 static/liveview 交替。** 原厂 `1017c020` 从 live input+49重写 context+5d，6对取景构造结果一致；回到静态入口后候选再次清位。这是原厂状态函数检查，不等于已覆盖完整真机模式切换。
5. **modified3 / LAB 两次 QEMU 调用跟踪，33 / 34条事件。** LAB静态 input+45=2，经 context+5d=2进入同一静态 builder；原有 RAW目的地址准备与临时阶段执行仍到达。模型零标定下主控制字原本已为0，因此只验证入口与传播，不提供新的像素消圈证据。

本轮物理效果仍以 modified3 实拍为准。新副本的假设是：单项前端控制可能参与尚未关闭的 RAW处理。bit11 的物理含义和真实机身置位状态要继续辨认；它也可能本来未启用，或与彩圈无关。

## 5. 下一步收敛与记录

1. 从 `c236d378` 的建立/复制来源追真正前端+259写入者；结合 ID38 的该项政策值及硬件参数关联确定处理身份。后端 `1013fa20` 同偏移对象另记，避免混接。
2. 对本轮确切 LAB哈希做安装前范围审查：两个静态调用点、完整模式返回、文件更新与回退。候选保留单一变量，不叠加未知位清零或全标定清空。
3. 审查通过后若进入实拍，以 modified3为A、新候选为B；机位/焦点/光源固定，慢快门主组、多信号级，1/8000秒另组。验实际 CFA环边而非标签归零，并回归112点暗场。宽光学/屏幕结构与细密量化环分别判断。
