# 首次候选实拍：112 点邻域抑制指纹从真实 NEF 中消失

日期：2026-11-09。输入：用户提供的 `samples/11.9_modified1/`，共 7 张 NEF。用户确认刷入的是最终审查包 `01_TEST/EG162080.BIN`，其中 4857–4859 是盖镜头的 bias，4860–4862 是盖镜头的 5 秒 dark，4856 是普通试拍；4862 的 f/20 是主动改变的对照条件。

**本轮取得第一项明确的实机像素结果：预先锁定的 112 个点，在原版两张暗场中全部呈现的 `max8 + 8×k` 指纹，在候选三张暗场中全部消失。这些位置的强暗信号实际写入了 NEF。** 这项变化与三指令邻域关闭候选的预期一致，支持候选整体确实绕过了对应的一类亮点／邻域抑制。下一步是缩短曝光避免热点饱和，并用回到原版后的复拍验证可逆性。

候选 SHA-256：`eeded80d4009204ba9760b6e20436aea3f6a37ce4ed6331ca662b839164a8875`。三处修改、更新前检查和风险边界见[最后审查](PREFLASH_REVIEW_2026-11-09.md)及[原厂控制链](RAW_CONTROL_CONVERGENCE_2026-11-09.md)。候选文件本轮没有再改动。

112 个位置的两帧平均值全部上升，最小增幅也为 3109 DN。周围邻居没有同步产生这种量级的抬升，说明这是局部强信号保留的变化，而不是整幅图统一增益或黑位抬升。候选 f/20 暗场同样保留这些强信号，单帧目标范围 3959–16383。

## 3. 变化超出这 112 点，但整幅暗背景仍围绕原黑位

全有效区大于 2008 DN（元数据黑位 +1000）的像素：原版两张为 139、134；候选三张为 2154、2110、2055。大于 1108 DN 的像素：原版为 394、361；候选为 14687、13689、12653。说明实际保留下来的暗场亮点不止冻结的 112 处；这些全幅计数是描述性结果，不把每一个新亮点都自动命名为同一算法的处理对象。

所有 bias/dark 的有效区零码值数量为 0，元数据 BlackLevel 仍为四路 1008。候选主 dark 的全幅均值约 1009.48、1009.21；原版约 1009.04、1009.04。普通背景分布仍围绕黑位，尾部和部分局部点发生明显变化。

按各自组内的 dark 均值减 bias 均值：原版整体为 +0.711894 DN，候选为 +1.128499 DN。这是实际保存码值之差；由于温度、时间不同，而且只测一个长曝光级，不据此计算物理暗电流率或“暗电流保留百分比”。bias 中目标点均值也从约 1530.87 变为 1358.79，进一步说明不能把跨时段差值全当作补丁增益。

可用于校准的数据现在包含更多热点，这是关闭抑制的预期方向；5 秒下已有不少热点饱和。饱和点的实际强度超出 14 位记录范围，下一次应加短曝光，让这些点落回可量测区间，再评估曝光增长和暗场校准。

## 4. 对最终目标意味着什么

| 目标 | 本次获得的实机证据 | 下一项验收 |
| --- | --- | --- |
| 关闭曝光相关局部亮点／邻域抑制 | 固定 112 点在三张候选 dark 中全部脱离旧指纹并保存强信号，支持本候选整体有效 | 同时段回到原版复拍；曝光、ISO、快门范围；星点保留 |
| 保留暗信号 | 原来被压回背景附近的高暗信号在 NEF 中出现 | 非饱和曝光序列、温度记录、外部暗场校准；整体暗电流统计 |
| 关闭全部静态 RAW 校正 | 本轮落实了一个局部处理候选的保存像素作用 | CPU 固定修复、前端、四负偏移、0x720、空间处理分别推进 |
| 消除彩圈 | 当前新增组主要是 bias/dark 和一张普通照片 | 同机身、相同光学条件的多亮度平场，核对 R/G、B/G 空间剖面与叠加 |
| 可用固件 | 用户确认刷入后拍摄，7 张文件保存和解码正常 | 实际回退、连续使用、更多拍摄模式和校准质量 |

这次补丁同时改变 props+4c/+4e/+4f，原厂链路使 bank+584/+594 为零。实拍支持这组修改与局部抑制的对应，但两条控制各自的职责仍需分离实验；没有把每一处寄存器都直接命名为独立的去星点算法。

原始固件、候选文件、之前的模拟器模型均没有改变。当前结论来自用户真机保存的 NEF，而不是像素模型。此前报告和包内“尚未实拍”的状态保留为出包时历史记录，最新状态以本报告为准。

## 5. 最小后续取样

先保留当前候选，不立即叠加新补丁。可在同一时段、ISO 1600、机械快门、14 位无损、两项降噪关闭、固定 f/1.8、盖镜头条件下：

1. 候选拍 3 张 1/8000 bias，以及 0.1 / 0.5 / 1 / 5 秒 dark 各 3 张。记录拍摄顺序、环境温度和间隔，避免长时间实时取景加热差异。
2. 完成候选序列后，如安排原版回退，按已审查的正常菜单回退步骤操作；原版补拍 3 张 bias 与 3 张 5 秒 dark，即可优先检验指纹是否恢复。无需为了每个曝光来回刷写。
3. 将回退组与候选组分目录保留原始 NEF。之后再补同机身平场推进彩圈，避免用另一台机身的旧 NAS 平场作补丁前后对照。

无需先改黑位、叠加全尺寸候选或尝试下一份固件。先把这条已经产生真实像素效果的修改做成可重复、可回退、可校准的结果。
