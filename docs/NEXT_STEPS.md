后续[图像事件追踪](IMAGE_COMPLETION_2026-11-02.md)确认图像状态 0→4、帧对象分配和资源初始化执行，静态连接 0x041f0004→0x0419000d→0x0415000d。候选 0x1013fd52 位于另一请求模式的资源条件失败分支，不能作为无条件成功出口；同编号事件还使用不同回调槽，必须区分。七个非零资源指针不等于有效 RAW 缓冲。

[11 月 3 日运行验证](SOURCE_TRIGGER_2026-11-03.md)在较长窗口中记录到完整结束通知链，等待位 0x100 已被原生消费者解除。后续 8 字节请求经 0x101484d0→0x10144b42→0x101424d2→0x10076a08 实际执行，图像状态推进至 6。当前序列阶段 0x800 等待位为 0x200，需要通知 0x0415000e。不要再把此前短窗口缺少 0x0415000d 作为必须新增完成中断模型的证据。

最新[收尾与帧队列追踪](PROCESS_COMPLETION_2026-11-03.md)已确认下层帧入队，队列计数为 1、依赖字段保持 0x1f，尚未命中消费者 0x100710ee。静态连接 0x041f0005→0x04190005→0x10146e60→0x1014a36a→0x0415000e。源控制的三处同步等待均返回成功，普通收尾路径已调用 0x100f6804→0x10193194；更长正常窗口最终仍在 0x200。不再将“帧未入队”或“这三处同步失败”作为主要假设。下层字段 0x1f 与上层等待位 0x200 分属不同对象。

同轮进一步记录到 0x10193194 通过 0x10190ebc 配置并启动定时器 8，对象 c18b7938 的时钟选择值为 0，回调为 0x10193181；未命中该回调。固定 QEMU 源码只为选择值 0x31 计数，日志仅有通道 8 的预置值、没有启动或到期。这作为已知模型限制保留，已降为辅助任务，不再是默认下一步。如果具体 RAW 处理的验证必须越过此处，再核对比例换算及驱动、以独立实验模式 A/B 验证回调和后续事件。不能把已支持 0x31 的 1 微秒假设直接套到选择值 0；尚未证明该缺口是全部阻塞的唯一原因。

0x27/0x2d 不直接当作故障或强制清除；0x27 的一次原生设置已定位到 0x10200cfa 内的 0x10200d10。物理按键到拍摄 API 的完整链条仍需独立补齐，无卡 API 实验不代表该链条已经打通。

与拍摄状态机研究分别推进源 ID 0x31 的物理含义、空间颜色增益、黑电平/裁切三个方向。先建立调用关系、参数来源、数据布局和硬件提交证据，再设计一项只验证一个假设的模拟器实验；不必等待整台相机都被模拟才能继续静态定位 RAW 处理。尚未实现的 ISP 硬件不能靠模拟器画面正常来验收。

借鉴 Z9 `deb3a75` 的验收思路：如果后续 Z6 打通照片保存，比较模型内 RAW 生产缓冲与实际文件经独立解码后的完整样本，再检查拍后恢复。不能拿模拟器的恒等降噪验证真实暗电流或彩圈；真机仍需原版与候选版本的暗场、平场对照。Z30 模块宿主可作为扩展机制参考，但不能直接移植地址或宣称 Z6 已支持。

## 设计最小修改

先针对一个已确认处理设计开关，再推进其他目标。每个候选补丁必须绑定输入哈希、检查原字节、记录控制流与校验和。不得把 Z30 或 DSLR 地址直接用于 Z6。

真机阶段前需明确安装路径、实际可用恢复路径及测试条件。单项 A/B 图像验收通过后再考虑组合补丁；保留原版结果作为对照。当前项目没有可刷的天文补丁。
