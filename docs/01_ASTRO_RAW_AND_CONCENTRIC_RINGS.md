# 专题报告 01：天文直通 RAW 链路重构与同心彩圈根除原理

> 🌐 **语言 / Language**: **简体中文** | **[English](01_ASTRO_RAW_AND_CONCENTRIC_RINGS_EN.md)** · 🏠 [返回文档索引](README.md)

## 1. 问题背景与实测现象 (The Concentric Rings Problem)

在尼康初代微单 Z6 / Z7 官方固件中，天文摄影用户在进行长时间曝光并叠加平场（Flat frames）后，无论在机身菜单中如何关闭「暗角控制」、「自动失真控制」与「衍射补偿」，经过深空后期极度非线性拉伸（如 STF / MaskedStretch），图像中心至边缘均会浮现出严重的**同心彩圈（Concentric Colored Rings）**。

### 1.1 实机物理采样现象
对原厂固件实拍平场进行直方图与傅里叶频域分析：
1. **直方图周期性缺码（Comb signature）**：
   在 R 通道与 B 通道的直方图中，像元计数并非平滑的泊松高斯分布，而是呈现极其规律的“梳状缺码”（某些码值像元数突增，相邻码值像元数为 0 或锐减）。
2. **固定频率谱峰**：
   经过 16384-bin FFT 离散傅里叶变换，在频域 $f = 0.2276\text{ cyc/DN}$ 处展现出极强的周期尖峰（周期约为 $T = 1 / 0.2276 \approx 4.39\text{ DN}$）。
3. **空间伪影本质**：
   这个固定周期源于前端 ISP 内部的一组 $2\text{D}$ 空间暗角调制多项式乘法器——即使菜单关闭暗角控制，硬件仍然在 RAW 压缩前强制注入微弱的径向非线性增益，导致 RAW 模数转换后的离散整数产生舍入间隙，破坏了天文线性校准基础。

## 2. 固件内部逆向与 14 处动态控制点

通过深入反汇编尼康 Z6 C3.80 图像处理引擎，我们定位到了全尺寸 RAW 在从传感器 DMA 进入 NEF 编码器之前的完整流水线：

```text
[ Sensor ADC 14-bit RAW ]
           │
           ▼
[ Frontend ISP (0x1017D834) ] ─── 原厂强制注入 2D 多项式增益 & 缺码梳齿
           │
           ▼ (frame+0x1f8)
[ Backend Buffering (0x100AE3A4) ] ─── 原厂替换为后端降采样/有损滤波缓冲
           │
           ▼
[ Hot Pixel Suppression (0x100C2654) ] ─── 原厂 3x3 邻域中值钳位 (吃星)
           │
           ├─► [ Lossless Bitstream Codec (0x100AF648) ] ─── 12/14-bit 无损压缩编码
           │
           └─► [ Uncompressed Hardware Bit-Packer (0x100A3480 / 0x100A34D0) ] ─── 12/14-bit 线性紧致位打包
           │
           ▼
[ File Writer (.NEF) ]
```

### 2.1 14 处门控拦截点（`fn_is_astro_r0` 统一架构）
为了在「直通RAW (sRGB)」开启时彻底切断所有非线性算子，同时保持小/中尺寸 RAW 缩放与无损压缩 / 未压缩双模式完全等价，固件挂载了 **14 处**动态分支跳板（Trampolines）：

1. **`0x100AE3A4` (全尺寸前端直通)**：
   将全尺寸 RAW（`size == 0`）直接从前端 `frame+0x1f8` 送入下游 NEF 编码器，完全跳过后端 `0x20380000` 替换缓冲区；对于小/中尺寸 RAW 保留原厂缩放逻辑。
2. **`0x100C2654 / 0x100C267C / 0x100C2690` (暗场邻域抑制旁路)**：
   跳过后端 $3\times 3$ 同色邻域中值滤波与强制暗电流剔除。
3. **`0x100C28B2 / 0x100C28C8 / 0x100C2964` (固定校准矩阵旁路)**：
   跳过第二阶段非线性暗角矩阵系数乘法。
4. **`0x1011E2DC` (前端数字乘数锁定)**：
   强制将四路色通道（R, Gr, Gb, B）的 Q12 数字缩放倍率锁定为精确的 $4096$（即 $1.0000\times$ 单位增益）。
5. **`0x10122CBC` (非空路径增益守恒)**：
   保持空指针安全防御的同时，消除空间调制增益。
6. **`0x1017D834 -> 0x1002D884` (前端 2D 多项式原地清洗)**：
   在 `0x1002D884` 注入清洗逻辑，清零全部 54 个径向/二维多项式系数，并将前端四通道 DC 增益归一化为 `16384`。
7. **`0x10197418 / 0x10197866 / 0x10197874` (元数据与黑电平钳位旁路)**：
   防止机内校准标志反弹污染下游 NEF 描述符。
8. **`0x100A34D0 -> 0x1002DB5C` (`tramp_a34d0` 未压缩硬件线性位打包器)**：
   当曝光时长 `>= 1s` 时前端采集描述符采用 `format = 3`（`16-bit LE` unpacked）。该跳板在未压缩编码路径 `0x100A3480` 中保持输入 `[r4+2] = 0`（`16-bit LE`），按目标位深将硬件打包器输出 `[r4+3]` 设为 `1`（`14-bit` packed，FX `42,920,960` B）或 `2`（`12-bit` packed，FX `36,780,160` B），且 `lut_ptr = 0` 纯线性无损位打包，确保 12/14-bit 无损压缩与未压缩在全快门范围（含 `30"~600"`）逐像素等价（详见 [MODIFIED23_UNCOMPRESSED_ASTRO_RAW_FIX_2026-11-18.md](MODIFIED23_UNCOMPRESSED_ASTRO_RAW_FIX_2026-11-18.md)）。

## 3. 真机实拍验证结果 (平场、偏置场与长曝光暗场)

针对同曝光设置的真机平场样片（直通平场 `Z61_5110.NEF` 与标准平场 `Z61_5119.NEF`，均为 1/8000s、ISO 1600、14-bit packed 编码）及长曝光实拍样片（`Z61_5128..5136.NEF`）进行严格量化核查：

| 测试指标 | 标准模式 (Standard sRGB, Z61_5119) | 天文直通模式 (Astro RAW, Z61_5110) | 改善与变化幅度 |
| :--- | :--- | :--- | :--- |
| **直方图外观** | 局部存在明显周期性缺码锯齿 | 曲线平滑连续，缺码特征消除 | 显著改善直方图平滑度 |
| **$0.2276\text{ cyc/DN}$ 最近频点幅值** | **$27,242$** | **$2,012$** | **下降约 13.5 倍** |
| **$0.22\sim 0.24\text{ cyc/DN}$ 频带峰值** | **$278,093$** (峰频 $0.2280$) | **$28,451$** | **下降约 9.8 倍** |
| **偏置场梳状齿 (Z61_5113 vs 5102)** | **$421,262$** | **$31,508$** | **下降约 13.4 倍** |
| **中心平场 R/G1 比值** | $1.0101$（经机内加权归一化） | $0.8997$（原生量子效率响应） | 解除非线性通道数字调制 |
| **`5s` / `60s` 未压缩 `packed-14` 全幅核验** | — | `42,920,960` B，与 `LibRaw 0.22.2` 逐像素 `0` 差异 | 全快门无损/未压缩逐像素一致 |

实机测试确证：开启「直通RAW (sRGB)」后，RAW 直方图的非线性梳状调制与机内色通道预缩放被彻底消除，平场校准不再引入虚假同心彩环伪影。
