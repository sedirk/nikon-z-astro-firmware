# 2026-11-08 接续：前端字段写入者、四路缩放系数与静态上传

本轮找到前轮九份 SPI8 配置报文的实际字段生成者，并连接到另一组四路前端缩放系数。**静态调用跟踪确认：原厂先生成这些字段，再上传四路系数，临时阶段结束后发送对应串行报文。** 八组非零对照与一次 QEMU 交叉重放验证了计算、内存和发送结果。

这使后续可以针对具体字段和使能／取样位置研究。当前成果属于原厂参数链，最终目标仍是保留暗电流、关闭静态 NEF 写入前的 RAW 校正和消除彩圈，并以保存像素与暗场／平场验收。

证据：摘要（`analysis/raw-front-field-writers-2026-11-08/evidence-summary.json`，本地归档未公开）、校验（`analysis/raw-front-field-writers-2026-11-08/verification.json`，本地归档未公开）、命令与日志（`analysis/raw-front-field-writers-2026-11-08/commands`，本地归档未公开）、精选原指令（`analysis/raw-front-field-writers-2026-11-08/curated-native.txt`，本地归档未公开）。前轮的[报文与标定资源来源](RAW_FRONT_CONTINUATION_2026-11-08.md)、[固定前端表](RAW_BODY_FRONT_2026-11-08.md)继续有效。

## 1. 已找到实际写入者，而非只有报文消费者

`10121ede(ctx)` 是本轮目标字段的生成函数。全局来源上下文为 `c18fa844`，标定基址来自 `*(c18fa954+14)`，以下简称 `cal`。

| 生成内容 | 实际写入位置／代码 | 下游 |
| --- | --- | --- |
| 第一对 12 位数值 | `10121ede → 10121d8a`，输出 `ctx+b0/b2`；实际半字写入 `10121eac/eb0` | SPI8 `81 00 3d` 报文 |
| 第二对数值 | `ctx+b4/b6`；条件分支另算，或 `101220f4` 复制第一对 | SPI8 `81 00 47` 报文 |
| 九个控制字节 | `101220b0..1012227a`，写入 `ctx+b8..c0` | 其余七份 SPI8 报文 |
| 四个缩放系数 | `10121f82/fa0/fb6/fce` 写入 `ctx+c4/d0/c8/cc`；另有条件缩放分支 | `1011e940 → 10122ca2 → c29a3868` |
| 配套控制字节 | `cal+be810 → ctx+d4` | 参数包 +18，驱动写入 `200687f0` |

`ctx+4/+8` 是计算使用的分母／分子；静态输入由 `100f63b4..63b8 → 101799c4..99ca` 原样传入。原 ROM `11b70474` 的九个参考值为 `15,18,21,24,27,30,33,36,39`，参与 `分母×参考值÷3` 的比较。在分母 192 时，对应输入比值 5–13。

这些输入与非线性码值、倍数分配呈现增益控制的结构。**具体 ISO 数字、模拟／数字增益的物理划分、各通道的颜色名称，尚未作为本轮已验证命名。** 脚本中的 `sv` 只是该有理数输入的实验标签，报告不据此直接指定用户菜单档位。

## 2. 码值与缩放系数怎样共同生成

`10121a1e(code)` 和 `10121a86(value)` 是一对整数换算。本轮按原指令独立计算，再执行原厂函数核对：

```text
F(code) = floor(10^12 / (10^6 - floor(code × 10^6 / 4095)))
G(value) = 0                                  当 value <= 10^6
G(value) = floor((10^6 - floor(10^12/value)) × 4095 / 10^6)  其余
```

四个直接对照：码值 0／2048／3580／4094 分别得到 1000000／2000488／7951401／4081632653；再逆换算得到 0／2047／3579／4093。整数截断使往返并不总是回到原值。

在本轮使用的“恰好落在参考点、调整量为零、来源模式 1”条件下：

1. `cal+be540+index*16` 的前两个 u16 提供两个原始码；`cal+be830+index*8` 提供四个 u16 倍数。
2. 原厂把两个码换算后分别分配给四项，乘标定倍数并右移 12 位。这里用 P0/P1/P2/P3 表示存储顺序，不指定 RGB。
3. 对 P0/P3、P1/P2 分别取较小值，再逆换算，生成两项码值；来源模式 1 在本轮高值对照中上限为 `0xf7e`（3966）。
4. 根据选定码值的换算结果，计算四项剩余比例，生成 `ctx+c4..d0`。运算包含乘 4096 与整数除法；比例与硬件实际单位增益的关系另行核实。

`ctx+28/2a`、`cal+be888/88a` 还参与两项比例；完整函数另外使用 `cal+be9a0` 开始的调整表，并可改变第二对码值。本轮非零夹具把这张调整表保持为零，未把参考点对照外推为完整插值和全部模式覆盖。

人工基线：生成两对相同码值 `[1383,1731]`，四个系数 `[4097,4097,4338,4865]`。只改变一项标定倍数后，第一项码变成 1685，系数变为 `[4096,4097,4338,4323]`。**码值与剩余比例存在耦合，单独清零其中一项并非已确认的中性化方法。**

## 3. 控制字节的具体来源

`10122edc` 比较输入分子是否达到分母的 8 倍；另一条件比较所选两项码的较小值与 `0xdfc`。这两个条件选择下列标定字节，再拼出控制位：

| 目标字段 | 相对 cal 的主要来源 |
| --- | --- |
| `ctx+b8/b9` | `be6a0..be6ad`，若干字段以左移 1／2 位后 OR 合并 |
| `ctx+ba/bb/bc` | `be6c0..be6c8`；bc 的最后一项左移 6 位 |
| `ctx+bd/be/bf` | `be6e0..be6e8`；bf 的最后一项左移 6 位 |
| `ctx+c0` | `be700..be703`：低 3 位、1 位、3 位以及最后一项，分别放在位 0／3／4／7 开始的位置 |

比值 7／8 的对照切换第一类选择，高码值对照切换第二类选择。单独改变 `cal+be700` 的低位，只有 `ctx+c0` 改变；四系数和前端寄存器保持相同。报文字段的用途继续保留为待识别的硬件含义。

## 4. 四系数的独立前端上传通路

原厂链已连接为：

```text
10121ede：生成 ctx+c4/c8/cc/d0
  → 1011e940(ctx, update)
  → 10122ca2(record, coefficients_or_null, control)
  → c29a3868；指针发布在 c29a34c0+38
  → 100bcd86 → 100bccd0 → 100d82cc → 1010b298
  → 200687d8 / 200687dc / 200687e0 / 200687e4
```

对本轮来源模式 1，`1011e940` 读取有符号字节 `cal+be821`，其四倍加到每个系数上。夹具该字节为 2，因此上传值由 `[4097,4097,4338,4865]` 变成 `[4105,4105,4346,4873]`。这个加法作用于**系数**，不应命名为对 RAW 像素的暗电流加减。

同一参数包另从 `cal+bbd70 + group*276 + index*12` 读取固定字段。本轮实际记录为 `cal+bbe78`，驱动上传到 `200687e8/ec/f4`；`ctx+d4` 则进入 `200687f0`。八组最终对照通过完整原厂参数回调和驱动，在私有 MMIO 内存中各记录八次写入，字节完全匹配。

**重要控制语义：`update=0` 会保留旧系数和旧控制字节。** `10122ca2` 的系数指针为零时，仍更新固定字段并发布参数包，却跳过复制四系数和控制字节。预填 `[7001,7002,7003,7004]` 与控制值 77 后，原厂照样把这些旧值上传。因此不能把“省略更新”直接当成关闭处理。

前轮已确定 `0x3e1` 的一个静态输入落点为 `ctx+5b`；本轮只针对这个落点做对照。把它改成 1，或单独把临时阶段 `ctx+84` 改成 1，当前模式下新字段、四系数和上传值均保持一致。其作用范围与偏移参数、固定表继续分别记录。

## 5. 静态运行时序与 QEMU 交叉重放

两次完整会话分别保存 64、107 条事件。第二次包含 26 条人工重放事件；每个外层调用最大 37 条，未触及重复断点 256 条上限。关键次序如下：

1. 同一静态帧已准备前端 RAW 地址 `a448e000`；主句柄为格式 2、6104×4222、跨度 9168。
2. `1017a136 → 10121ede` 实际执行；生成前后 `ctx+84=0`。
3. 临时阶段调用 `1017d81a → 1011e940(ctx,1)`，此时 `ctx+84=1`。
4. 参数包构造读取 `c97bbe78`，随后驱动 `1010b298` 从 `c29a3868` 读取并上传；返回地址对应 `100bcd46` 的原厂调用。
5. 临时阶段结束，发送前轮已识别的 SPI8 报文。

原状态的相关数值标定为零，所选记录和上传系数也为零。该观察用于确认真实调用关系和位置，不用来判断校正效果。静态后端处理、替换写回和 NEF 编码观察点在本轮窗口仍未命中。

人工交叉重放在同一次 QEMU 的独立实验阶段进行：临时替换已列明的标定片段，使用 scratch 上下文调用原厂生成器和发布器。完整 0xe4 字节上下文与 32 字节系数参数包均与 Unicorn 结果逐字节相同；全局来源上下文未改动，指定标定和参数区逐字节恢复。随后调用 kind 4，得到：

```text
81003d6705c306    8100476705c306    810055bd
81041f43        81042447          8105a621
8105a822        8105e10605        8105f74142
```

九份报文与提交描述符中的 u16 数据以及 SPI8 日志一致。沿用的 SPI8 模型仍是记录发送数据的断开设备收发端，没有实现对应传感器响应；人工重放不代表实际曝光。

## 6. 对最终目标的取舍

| 路径 | 当前定位 | 接下来解决的问题 |
| --- | --- | --- |
| 本轮两对码值、四系数 | 原厂生成者、标定字段、控制选择、静态上传、非零发送均已连接 | 配套控制字的物理语义、前端处理相对主 RAW 采样的位置 |
| 前端正标量、后端四路负偏移／0x720 | 保留此前数值、门控和请求／写回路径证据；与本轮系数分开 | 哪个处理实际改变暗信号，怎样传到最终编码输入 |
| 固定 32 组表／144 项表 | 保留前轮选择、复用、上传与临时阶段证据 | 空间索引、使能、真实样本覆盖与彩圈关系 |

本轮函数直接生成的是少量码值、控制字和全局系数，已观察的计算没有按像素坐标遍历二维空间。因此把它作为增益分配与通道比例候选继续核对，**不先把它命名为彩圈的空间校正算法**。这项取舍用于避免在普通增益配置上扩展过多支线；下一轮重点回到前端控制、静态 RAW 取样及四路负偏移／0x720 的真实写回。

真实机身标定区的内容、硬件执行和最终 NEF 样本仍是独立的证据层。模拟器的简化图像算法未用于暗电流或消圈验收。
