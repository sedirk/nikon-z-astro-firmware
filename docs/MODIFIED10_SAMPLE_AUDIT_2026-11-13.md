## 2. MakerNote 元数据审查 (NEFInfo)

通过分析样张 TIFF/MakerNote IFD 中的关键校正标签：
- **`NEFInfo 0x6` (暗角 257 节点曲线)**:
  - `status = 2`
  - `L = 0`
  - `coeffs = [0, 0, 0, 0]`
  - **结论**: 暗角中立化保持完好，校正多项式高次项为 0。
- **`NEFInfo 0x7` (空间双 17 同心环)**:
  - `flag_at_4 = 1`
  - `flag_at_5a = 0`
  - `coeffs = [32, 0, 0, -16, 0, 0]` 等低阶常数
  - **结论**: `Modified10` 对 `+0x5a` 活跃标志的置 0 补丁彻底奏效，**完全杜绝了 Modified9 中空间校正表意外反弹激活（当时 flag_at_5a=1）的现象**。

## 3. 核心突破：数字通道乘法器（梳状齿）的源头定界

### 3.1 实测 FFT 梳状齿对比
在样张中心 `400×400` 均匀平场区域提取四通道原始 ADU 序列并计算直方图 FFT 频谱：

| 固件版本 | 红通道 R 峰值频率 / 周期 | 蓝通道 B 峰值频率 / 周期 | 绿通道 G1 周期 | 绿通道 G2 周期 |
| :--- | :--- | :--- | :--- | :--- |
| **Modified9** (`Z61_4945`) | $f=0.2280 \text{ cycles/ADU}$ ($T=4.39 \text{ ADU}$) | $f=0.2096 \text{ cycles/ADU}$ ($T=4.77 \text{ ADU}$) | $T=7.19 \text{ ADU}$ | $T=4.10 \text{ ADU}$ |
| **Modified10** (`Z61_4955`) | $f=0.2276 \text{ cycles/ADU}$ ($T=4.39 \text{ ADU}$) | $f=0.2093 \text{ cycles/ADU}$ ($T=4.78 \text{ ADU}$) | $T=7.19 \text{ ADU}$ | $T=4.10 \text{ ADU}$ |
| **Modified10** (`Z61_4956`) | $f=0.2280 \text{ cycles/ADU}$ ($T=4.39 \text{ ADU}$) | $f=0.2101 \text{ cycles/ADU}$ ($T=4.76 \text{ ADU}$) | $T=7.19 \text{ ADU}$ | $T=4.10 \text{ ADU}$ |
| **Modified10** (`Z61_4957`) | $f=0.2280 \text{ cycles/ADU}$ ($T=4.39 \text{ ADU}$) | $f=0.2096 \text{ cycles/ADU}$ ($T=4.77 \text{ ADU}$) | $T=7.19 \text{ ADU}$ | $T=4.10 \text{ ADU}$ |

### 3.2 物理推论与管线定界
1. `Modified10` 的核心改造是通过 `REQ+0x1a8 = 0` **彻底绕过了整个后端 ISP 渲染引擎 (`0x20380000`)**，无损编码器直接从前端传感器缓冲区 (`frame+0x1f8`) 读取原始数据。
2. 实验证明：**完全绕过后端 ISP 之后，直方图梳状齿的周期（R 4.39 ADU、B 4.77 ADU）与幅度谱线完全未发生任何改变**。
3. **确定性结论**:
   - **数码通道乘法器不在后端 ISP (`0x20380708 / 0x2038070c`) 中！**
   - 梳状齿产生于 **前端管线到达 `frame+0x1f8` 之前**。
   - 具体候选目标锁定为前端数据流进入前的两个环节：
     1. 前端 Q12 数字增益乘法器 (`0x10121ede -> 0x1011e940 -> 0x200687e8..87ec`，Operator 12)。
     2. 前端 Sony 读出标定曲线/非线性映射 (`CAL33` 读出表，位于 `0x1011e2ce -> 0x20068f00..8fc8`)。

## 5. 下一步收敛策略 (Modified11 方案)

既然实机已确证数字乘法器位于前端管线（进入 `frame+0x1f8` 之前），收敛方案聚焦于：
1. **中立化前端 Q12 增益比例器 (`0x10121ede` / `0x1011e940`)**: 将通道乘数强制设为 `0x1000` (1.0x 单位增益)。
2. **中立化前端 `CAL33` 读出表 (`0x20068f00`)**: 将传感器读出校正表置为理想线性直通 $y = x$。
3. 提示用户后续拍摄 DARK/BIAS 样张以复核热像素与暗电流保留情况。
