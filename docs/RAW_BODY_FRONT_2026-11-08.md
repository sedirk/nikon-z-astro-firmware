# 2026-11-08 接续：机身侧标定块、前端表与临时配置阶段

本轮沿机身侧标定块新增连通两条前端表通路，并观察到静态拍摄过程中实际上传。**关键进展是识别了临时配置阶段，以及一条与短曝光数值有关的表生成支线。** 这些结果帮助收窄长曝光天文 RAW 的排查范围。四路负偏移和 `0x720` 继续作为独立主线，最终验收仍是保存的 NEF 像素和暗场／平场效果。

最终有效证据为两次 QEMU 会话（32／42 条记录）、九组／45 段原厂隔离执行、1,926 次私有 MMIO 写入。第一次七组隔离结果作为迭代记录保留，不与最终九组重复累计。参见摘要（`analysis/raw-body-front-2026-11-08/evidence-summary.json`，本地归档未公开）、校验（`analysis/raw-body-front-2026-11-08/verification.json`，本地归档未公开）、命令（`analysis/raw-body-front-2026-11-08/commands`，本地归档未公开）、精选原指令（`analysis/raw-body-front-2026-11-08/curated-native.txt`，本地归档未公开）。

## 1. 标定块的身份与共同来源

原厂初始化 `100f5912..5918` 调用 `101f624a(0x38)`，经 `1017921a → 1011b6f4` 把返回地址写入 `c18fa954+14`。目录 getter `101b0856 → 10091d94` 返回目录项 `+8`。

| 字段 | 原版映像中的目录记录 | 本轮模型运行值 |
| --- | --- | --- |
| 记录位置 | `11f1606c` | `c1881298` |
| ID | `0x38` | `0x38` |
| +8 数据指针 | 0 | `c9700000` |
| +c 长度字段 | `0x168000` | `0x168000` |
| +14 数值字段 | `0x18` | `0x18` |

ROM 与 RAM 记录除了数据指针以外逐字节相同。**这是目录和消费者的证据；“每台机身独有标定”与“型号共用参数”仍需通过实际装载者和数据来源区分。** 本轮不把这个地址直接命名为逐机 EEPROM。两次会话读取的选中记录均为零，记录中没有真实机身的标定样本。

该块同时提供以下数据，偏移均相对 `*(c18fa954+14)`：

| 偏移／选择器 | 原厂消费者 | 已定位目的地 |
| --- | --- | --- |
| `bc7f0 + group*396 + index*12` 的 +6 | `1011ebb8`；另见原四标量 getter | 前端 `20068808` 低 16 位；后端四路负偏移／`bank+720` 的上游输入 |
| 固定 `293c0`，或 `73c0` 开始的多维记录选择 | `1011dce0 → 1011dcb2` | 四通道 ×32 个 u16，`20068a00..20068afc` |
| `2d984 + index*588` | `1011e118 → 1011df8c` | 两张各 144 个 u16 的表，`20068c00..20068e3c` |
| `126900 + group*8080 + position*4`、`1306d0` | `1011df8c` | 上一行第二张表的计算与上限 |

“同源标定块”与“同一物理处理”分别记录；表项尚未赋予 RGB 顺序、像素坐标或具体校正名称。

## 2. 32 组四通道表

`1011dce0` 在来源类型不属于 0／1／2，或上下文 `+84 != 0` 时选择固定记录 `cal+293c0`。另一分支使用上下文、时间换算和阈值表选择记录，位于 `cal+73c0` 开始的区域；本轮重点验证固定记录分支。

`1011dcb2` 把 256 字节复制到 `c29a38a0`，发布为参数包 `c29a34c0+44`。回调链为：

```text
100bcd86 → 100bccd0 → 100d82f4 → 1010b330
```

驱动把相邻两组的同通道 u16 合为一个 u32，每通道 16 次写入，四个起点为 `20068a00 / a40 / a80 / ac0`。人工非零记录逐字节验证通过；只改变第 5 组、通道 2 的一个值，只改变 `20068a88` 一个配置字的高半字。这个实验验证数据传播，表的硬件运算意义留待继续定位。

## 3. 两张 144 项表：选择、复用和时间条件

`101228ec` 仅在 `ctx[0]` 为 0／1 且 `ctx+21 == 2` 时返回 1。`1011e118` 据此选择：

- 返回 0：`index=1`，指向 `cal+2dbd0`。
- 返回 1：`ctx+78 < 175` 时 `index=ctx+78+1`，否则 `index=0`。

`1011df8c` 遇到 `cal+2dbd0` 这个特定地址时，只更新 12 字节控制块，**沿用两张旧表，继续发布和上传它们**。这不是清零表，也不是明确禁用硬件。人工预填的 144 个不同旧值在原厂执行后完整保留并上传。

其余记录分支：表 A 来自记录 `+a` 的 144 个 u16；表 B 使用记录 `+12a` 的 144 个 u16、表 A 的累加值、时间换算结果，以及上述机身侧附加表计算。`ctx+34` 选择五组附加数据，具体字段名继续保留为数值标签。

表 B 的直接门控是：若 `ctx+10 <= 10 * s16(ctx+c)`，或 `ctx+74 != 0`，写入常数 `32768`。在标准分母 192 的人工输入下，原厂 `1011c14a` 的时间换算与独立整数计算一致：

| 时间输入 | 原厂换算结果（以 ns 表示） | 表 B 的 144 项输出 |
| --- | --- | --- |
| 约 1/8192 秒 | 122070 | 本轮非零标定夹具产生 38880–62000，共 62 个不同值 |
| 约 1/1024 秒 | 976562 | 全部 32768 |
| 1 秒 | 1000000000 | 全部 32768 |
| 256 秒 | 256000000000 | 全部 32768 |

额外的 `ctx+74=1` 对照也得到全 32768；将 `cal+1306d0` 上限从 62000 改为 35000，本夹具得到全 35000。驱动 `1010b37e` 用原厂未对齐读取函数 `101f6182` 把 A、B 分别上传到 `20068c00`、`20068d20`，每张 72 个 u32。

**研究取舍：降低这张表动态计算分支作为长曝光彩圈根因的优先级。** 这是由时间条件支持的推断；`32768` 是否对应硬件单位增益、固定表／旧表是否影响曝光数据，分别继续核对。尤其默认记录走“旧表复用”，不能把重新生成分支的长曝光结果外推到所有路径。

## 4. 静态拍摄的实际时序

本轮使用既有无电子镜头 QEMU 设置、合成输入和诊断 CaptureWithoutCard；未新增设备算法或完成事件。断点每个外层调用只取一次，因此下列是观察到的次序，不是所有调用或总线写入的完整清单。

第二次会话记录了：静态对象提交 → 同一主 RAW 句柄的前端地址准备 → `10179d4a` 即将把 `ctx+84` 置 1 → 新表生成／上传 → `10179da4` 调用等待接口 → `10179da8` 返回值 1 → `10179dd4` 清除 `ctx+84`。最终上下文 `+84=0`。

这次临时阶段中：

- 来源模式为 1，`ctx+21=0`；32 组表选中 `c97293c0`，144 项记录选中 `c972dbd0`。
- 32 组表来自模型内零标定；144 项表沿用零旧表，两组驱动实际执行。
- 参数包分发返回地址 `1017d83b`，对应 `1017d7b6` 的原厂构造／提交链；其调用点为 `10179d7c`。
- 主 RAW 地址仍为 `a448e000`，格式 2、6104×4222、跨度 9168，与[前轮写回研究](RAW_WRITEBACK_2026-11-04.md)一致。

因此，新表已经具有静态流程联系，观察位置属于明确的**临时前端配置阶段**。清除该标志之后是否再次编程、每批参数覆盖哪些真实样本、RAW 取样点在处理前还是处理后，是接下来要闭合的关系。两次会话的静态后端处理 `100ae33e`、替换写回 `10106980` 和编码 `100af648` 仍列为未命中观察点；模型中取景的四偏移上传单独归类。

## 5. 与四路负偏移、0x720 的关系

在同一非零标定夹具中，将 `ctx+5b` 从 0 改成 1（它是前轮验证的静态 `0x3e1` 输入落点），前端 `20068808` 的低 16 位从 300 变成 0，32 组表、144 项表及各自的上传字节保持一致。两次完整配置轨迹仅该寄存器值不同。**这表明这个偏移门控没有覆盖本轮两组表的配置路径。**

既有[偏移／NEF 研究](RAW_NEF_INFLUENCE_2026-11-03.md)与[输出路由研究](RAW_OUTPUT_ROUTING_2026-11-03.md)已把同一标量接到四个负偏移和 `bank+720`；本轮进一步区分了它与其他前端表的作用范围。当前证据层次为：

| 项目 | 已验证事实 | 待闭合的目标关系 |
| --- | --- | --- |
| 前端正标量 | 标定记录、门控、寄存器写入 | 具体偏置／钳位运算和主 RAW 取样位置 |
| 四路负偏移、0x720 | 原厂数值生成、配置上传及静态请求联系 | 实际处理写回是否改变最终编码的样本 |
| 新 32 组表 | 固定记录、逐字上传、静态临时阶段 | 固定标定含义、清除临时标志后的配置和像素效果 |
| 新 144 项表 | 默认复用、时间门控、计算和完整上传 | 旧表覆盖范围及硬件常数表语义 |
