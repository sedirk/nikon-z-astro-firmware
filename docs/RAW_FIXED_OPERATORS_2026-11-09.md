# ID35 定长区：静态调用专用候选与 33×4 隔离验证

2026-11-09。接续 [空间身份调查](RAW_SPATIAL_IDENTITY_2026-11-09.md)，目标保持：保留暗电流、关闭静态 NEF 写入前的 RAW 校正并消除彩圈。实验使用原固件和 modified4 的副本；本轮没有操作相机或存储卡，没有新增实拍。

## 本轮推进

**已做成一个仅在指定静态调用点清零 ID35 控制的 LAB 候选。** 非零标定对照中，这个候选明确改变原生控制值，并让原生 ID35 选择器跳过定长表提交；再次执行普通配置后恢复原标定值。33×4 表、其报文以及 507 次前端寄存器上传保持一致。这使下一步实拍可以单独检验 ID35 这一路，而不同时改两种未知表。

当前完成的是调用范围、原生关闭条件和精确副本验证。ID35 定长数据的逐像素硬件算式，以及 33×4 是空间坐标函数还是信号域查表，仍列为待识别项。候选不是已经验证消圈的固件，也还不是完成安装前审查的 modified5 刷机包。

原版、modified1–4 及既有暗场补丁保留。实拍结论沿用 [modified4 比较](MODIFIED4_REAL_NEF_2026-11-09.md)：宽颜色起伏没有整体一致改善；最后一次新暗场实机回归来自 modified3。本轮保留暗场补丁的字节，不将其等同于新的暗场实测或全部暗电流恢复。

## 1. ID35：已接通的实际控制与数据路径

以下地址、偏移用十六进制；特别标注的数量为十进制。

```text
静态调用 10179d56
  → 1011c750(kind=0, context)
       → 1011c64e：选 0..27 或 ffff
       → CAL38 + 540 + index × 80（十进制）
          byte0 → c29a3230+1c → 10110c08 → 100cd64a → 2006103c
          byte1 → c29a3230+20 → 20061040
          byte2 → c29a3230+26 → 20061048
          byte3 → c29a3230+7c → 20061138（布尔转换）

后续 kind=1、temporary!=0
  → 1011c3f4
       global+1c == 0：正常返回，跳过 ID35 定长表提交
       global+1c != 0：按模式选 ID35 区间
          → 101229b8 → 100cda34 → 20061264/20061268（指针/长度）
```

已观察的 mode1 路径选 `ID35+acdf0`，长度 **24,416 字节**。该长度等于 6104×4，但此算术关系本身没有确定元素的类型或列校正算法。此前确认的 ID0b 离散位置流是另一个消费路径，不能拿它的 x/y 编码说明 ID35 这个定长区的身份。

**本轮验证的关闭条件是软件控制零值及相应寄存器写零、停止提交。** 它通过原生上传函数实际写入 `2006103c`，不只是让上层跳过一个函数。跳过表提交时，旧描述符内容仍保留；因此本候选的设计依据是明确的控制写零，不能把“描述符没有变化”说成清空了校正表。硬件收到零值后怎样处理 RAW 像素，必须由真实硬件定义或 NEF 对照进一步落实。

原生调用与恢复记录（`analysis/raw-fixed-operators-2026-11-09/native-static-call-v3/result.json`，本地归档未公开）保存了各字段、寄存器写入、context、返回值、栈和服务调用。

## 2. 为什么不用临时状态作全局关闭条件

先做过一个“kind0 且 context+84 非零就关闭”的候选。范围复核找到 **18 个临时标志写入点、9 组成对设置/清除路径**；这一条件比目标调用点宽，不能把它直接命名为静态专用。因此该副本保留为被淘汰实验，状态见 `analysis/raw-fixed-operators-2026-11-09/lab-module/DISPOSITION.json`（本地归档，未公开），不进入安装准备。

最终 LAB 使用明确的调用点标记：

1. 在 `10179d54` 将传给 `1011c750` 的 kind 从0改为私有值4。
2. 分发器保留原值供这一处判别；查找标定记录仍使用去掉 bit2 的普通 kind，因此4选择原 kind0 记录。
3. 在 kind0 构造块中，仅对该标记清零第一个控制；其它三个标定字段照原样复制。
4. 原 `10110c08` 调用、返回分支和既有字面量位置保持；不增加文件长度、跳板、代码洞或新的固定地址。

找到并检查的 **49 个直接调用点**原本都传0、1或2。新候选只有 `10179d56` 传4，其余48处保持。奇地址函数指针字面量扫描没有发现 `1011c751`，替换块的已找到入口保持；这属于有界静态检查，不是对所有间接控制流的穷尽证明。有效输入约定为普通0–2和私有4，未把任意损坏参数纳入兼容承诺。

“静态调用专用”指新增行为仅在上述已定位调用点触发。该静态前端可能被其它静态格式或模式共用，尚未细分为 NEF 文件类型独占，也未声称覆盖所有连拍、电子快门和视频模式。

## 3. 33×4：隔离保留，继续追真实运算

已有链路继续核对：`CAL38+47180+group×600+category×300`（乘数十进制）是一条300字节记录，含36字节头和132个 u16。`1011e2ce → 1011e23e` 选择/复制后，经 `100bccd0 → 100d830a → 1010b3a8` 上传到四组寄存器。

四组上传基址为 `20068f00、20068f44、20068fcc、20068f88`；每组写17个 u32，包含末项打包的行为。记录头的四对 u16 和后续数值分别进入 `200686e4..20068714`。这些去向已确定，尚未把头部四对数值认定为中心坐标，也未把整张表认定为径向增益。

`20068708` 的选择行为带交替/强制逻辑，空报文会保留旧表，均不作为已知关闭手段。选择器有19个已找到直接调用点，静态一侧为 `1017d7f0`。详细映射保留在 [上一轮报告](RAW_SPATIAL_IDENTITY_2026-11-09.md)。

本轮填入明确标注的非零人工记录，执行原生静态构造和原生上传：modified4 与新 LAB 的报文、132项表、前端寄存器及 **507 次写入逐项相同**。这些是原厂指令执行证据，不是模型生成的校正图；它证明本候选没有顺带修改这一路的已测配置。

另外复查了 ID35 偏移字面量、相关立即数和可读标签。`a6e90` 的7处额外字面量命中实际为 UTF-16 界面文字中“源”和换行的组合，不是处理函数。前5 MiB 的有界立即数候选搜索未找到新的可信逐像素消费者；保留候选及反汇编，不据此断言固件中不存在其它引用。公开资料查询也没有补出与这些 Z6 寄存器一一对应的运算定义，见 来源记录（`analysis/raw-fixed-operators-2026-11-09/source-notes.json`，本地归档未公开）。

## 5. 验证、失败记录及证据边界

| 检查 | 结果 |
| --- | --- |
| 原生差分 | 主矩阵224对，补充20对，共244对；普通调用结果一致，带标记调用只改变预期控制 |
| 选择器域 | 补充实验每版1024次，共2048次，覆盖0..27及ffff；包含 context+21 子模式 |
| 调用约定 | 成功差分中返回值、r4..r11、SP、最终 CPSR、context 一致；标定源保持 |
| 保留内存顺序 | modified4 控制17→17→17；LAB 为17→0→17；静态期间跳过 ID35 提交，普通配置后恢复 |
| 33×4 隔离 | 两版各执行原生构造和507次上传，表/报文/写入一致 |
| QEMU | 两版均到达 RAW 目的地址准备、静态分发、正常返回、33×4 构造和临时状态退出；分发0,1,2与4,1,2符合设计 |
| 独立字节审查 | 精确重建、53个变化字节的范围白名单、继承补丁和保护区域通过 |

原生差分使用私有 RAM 承载 MMIO；只将两个 RTOS 互斥包装器 `10170df0/10170dea` 适配为成功返回。没有代写传感器像素、伪造 DMA 完成或添加 Nikon 像素算法。CAL 记录是非零测试夹具，非机身标定转储。

QEMU 使用既有零 CAL、传感器和 RTOS 测试环境，四个模型源文件哈希两次相同。零 CAL 下原控制已经为零，所以 QEMU 用于检查调用路径，不用来评价关前关后的校正幅度。目标调用前 RAW 参数块 `c25ee224` 的前 `0x28` 字节相同，主目的地址为 `a448e000`；其后 `+28..+40` 七个地址样式字段不同，已完整记录。其它指定事件的所采内存快照一致。七个字段的完整归属未闭合，未宣称整个 RAW 缓冲分配一致，更没有据此声称最终 NEF 像素一致。

保留的失败和修正：

- 12号实验：验证器错误要求所有模式返回0；原版 mode13/temporary1 本来返回1。改为对照返回值，并只对支持的带标记调用要求0。
- 13号实验：224对及恢复顺序已通过，后续构造访问了未映射的 ID0b 辅助区。测试映射从1 MiB 扩至4 MiB，覆盖其 `+1f8000` 辅助记录；未为通过测试改固件。
- 主矩阵的早期选择器扫描误改 context+1，缺索引4..7；20号补充实验改为真实 context+21，并补20对测试。主矩阵不冒称覆盖完整域。
- 21号独立审查：错误要求 QEMU 采集的整个参数块跨运行相同。22/23号保存七个差异并核对原生写入范围；24号按明确字段范围审查，差异继续列在结果中。候选字节保持。

成功证据：主矩阵（`analysis/raw-fixed-operators-2026-11-09/native-static-call-v3/result.json`，本地归档未公开）、补充（`analysis/raw-fixed-operators-2026-11-09/native-submode-supplement/result.json`，本地归档未公开）、独立审查（`analysis/raw-fixed-operators-2026-11-09/independent-review-v2/result.json`，本地归档未公开）、QEMU 差异（`analysis/raw-fixed-operators-2026-11-09/qemu-differences.json`，本地归档未公开）。

## 6. 下一步向实拍收敛

先对本 LAB 的确切哈希完成独立安装前审查，保持 ID35 一个新增功能变量。实际像素验收以“modified4 → ID35 静态关闭候选”为一对，33×4 保持，以便看见 ID35 与最终 NEF 的关系。

实拍布置须固定相机、光源、距离、角度和手动焦点；历史平场只作参考。以能平均屏幕条带的较慢快门、多信号级、不饱和 CFA 数据为主，另留原1/8000秒条件；每档至少三张。同时补 ISO1600、5秒盖镜头暗场和同 ISO bias，回归冻结112点。先比较细环的半径/幅度及重复性，再单列宽颜色起伏；新候选若出现一致变化，再用回退复现确认归因。

另一条证据路线是获得真实机身 CAL38 的选中记录和 ID35 定长区的只读副本，结合真实控制状态区分：原控制本来为零、控制改变但无像素效应、或输出确有固定模式变化。33×4 在得到真实运算定义或可靠关闭条件之前继续保留，不猜单位表、不用修改模拟器算法代替证据。
