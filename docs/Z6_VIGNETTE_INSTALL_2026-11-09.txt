Z6 C3.80 modified2：安装与回退步骤（2026-11-09）

这份候选已通过离线安装前审查，可以开始受控实机测试。
它保留你当前 modified1 的暗场补丁，只新增 257 项暗角曲线中性化。
modified2 的开机、拍摄、消圈和实际回退尚待实机验收。

本包仅用于初代 Nikon Z6 C3.80。当前基线是你已安装并拍出 NEF 的 modified1。
三个文件名称一样，必须按文件夹和哈希区分：
  01_TEST_MODIFIED2/EG162080.BIN    本次测试候选
  02_BACK_TO_MODIFIED1/EG162080.BIN 回到现在的暗场补丁，撤销新增曲线修改
  03_STOCK_C380/EG162080.BIN        回到未修改的原版 EG，撤销两项修改
三份均为 33,502,842 字节。菜单版本仍显示 3.80。

一、先留 A 组，避免多刷一次
先按 FLAT_COMPARE.txt，在当前 modified1 下拍 A 组平场及暗场。
保存原始 NEF 与 SHOT_LOG_TEMPLATE.txt 中的条件，拍完后保持机位和镜头设置。
旧 4864/4865 是 1/8000 秒、ISO1600、f/1.8；不能当成新 ISO100、f/8 组的配对基线。
本轮不要求为了“练习”额外刷回原版，也不需要为每档曝光来回刷写。

二、准备
1. 确认是一代 Z6、C3.80，当前确为本项目 modified1；不同机型或混装其它修改时先停止核对。
2. 备份卡上照片和要保留的设置。相机设置文件并非 flash/NVRAM 备份。
3. 使用充满电且状态可靠的兼容电池；保持电池接触和供电稳定。
4. 使用之前工作正常、相机支持的 XQD/CFexpress 卡和可靠读卡器。
   若要格式化测试卡，先确认照片已有备份，再在相机内格式化；格式化会删除卡上数据。
5. 保持单张拍摄；更新时断开 USB、HDMI、快门线等外接连接。镜头可保持安装以保留平场几何。
   更新期间不要拆装镜头、附件或操作相机。不要使用不稳定的临时供电方案。

三、校验电脑里的测试包
在项目根目录 <repo-root> 的 PowerShell 中运行：
  .\work\re_env\Scripts\python.exe .\outputs\Z6-C380-vignette-neutral-reviewed-2026-11-09\verify.py
必须返回 "ok": true。ZIP 先完整解压；换电脑时在解压包内运行 python verify.py 即可，使用标准 Python。
校验工具只读，不复制、不格式化、不刷写，不会自动选择回退文件。

四、确认回退文件和卡上回读
如果之前已经确认当前 modified1 能识别原版 EG 更新文件，可保留当时记录；否则先做一次识别检查：
1. 关机取卡，电脑中只将 03_STOCK_C380/EG162080.BIN 复制到卡根目录。
2. 安全弹出，再插回读卡器，执行下列命令。
   E:\ 仅为示例，必须换为测试卡的实际盘符，不能直接照抄：
  .\work\re_env\Scripts\python.exe .\outputs\Z6-C380-vignette-neutral-reviewed-2026-11-09\verify.py --card-root E:\ --mode stock
3. 通过后安全弹出，关机状态插卡；开机进入“设置菜单 → 固件版本”。
   查看本机 C 固件 3.80 对应更新入口，最终确认选择“否／取消”，此步不刷原版。
4. 没有入口、机型／组件异常或有报错则取消并记录画面，不改版本号、不绕过拒绝提示。
这一步只是菜单识别检查，不代表不开机时也能恢复。

五、复制测试文件并安装
1. 正常退出并关机取卡；电脑上移除卡根目录旧固件文件，只保留电脑中的所有回退副本。
2. 从 01_TEST_MODIFIED2 复制 EG162080.BIN 本身到卡根目录。
   卡根目录只放这一个固件 BIN，不拖入整个测试包，不加入 WonderLantern core 或旧 .bin.lab。
3. 安全弹出后重新插入读卡器，做实际卡上回读：
  .\work\re_env\Scripts\python.exe .\outputs\Z6-C380-vignette-neutral-reviewed-2026-11-09\verify.py --card-root E:\ --mode test
   仍须替换示例盘符；必须返回 "ok": true 且 mode=test。
   可保存输出截图；不带 --card-root 的校验只检查电脑文件。
4. 安全弹出，关机状态插卡。开机进入“设置菜单 → 固件版本 → 更新”。
   预期仍为 3.80 → 3.80。确认组件、文件、电量均正常后，由你手动确认。
5. 更新中保持供电，不关机、拔卡、拔电池或操作附件。遵从屏幕指示等待。
   若看似停止，先保持供电并记录画面／指示灯／已过时间，不按自行猜测的超时拔电池。
6. 屏幕明确提示完成并要求关机后，再按指示关机。保存成功画面、时间和所用文件哈希。
7. 使用没有固件 BIN 的拍摄卡开机，先检查菜单、回放、普通单张 NEF。
   确认普通 NEF 能保存、在电脑完整解码，再拍 B 组。预览能显示不等于完整 RAW 已验证。

六、回退选择
相机仍能正常进更新菜单时：
  想撤销本次曲线修改、保留暗场补丁：02_BACK_TO_MODIFIED1，校验 --mode modified1
  想撤销所有实验修改：03_STOCK_C380，校验 --mode stock
按第五部分相同步骤操作，只替换来源文件夹和校验 mode，卡上一次只有一份。
相机版本仍是 3.80，保留哈希与更新完成记录；回退后拍同条件 C 组可验证恢复。
正常完成 A/B 后不要求立即回退；若出现拍摄错误、花屏、异常停机，停止扩大测试，
在相机能正常操作且未处于更新写入时按上述路径恢复。

剩余的主要风险
本次仍是整个主固件区擦写，小补丁不代表只写几个字节。断电／硬件写入故障仍可能导致无法启动。
两份回退文件适用于正常菜单；未验证不开机救砖，也没有这台机身完整 flash/NVRAM 备份。
无法启动时可能需要维修或硬件编程。离线模型的错误重试不是自动回滚。
官方完整原文件仍保留于 firmware/original/Z_6_0380.bin，本轮没有修改或替换它。
