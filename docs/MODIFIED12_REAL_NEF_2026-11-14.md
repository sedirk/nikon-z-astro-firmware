## 1. 核心结论摘要（严格基于实测数据边界）

1. **离线控制流修复验证与实机留存样本无损解码通过（严格区分两类证据）**：`Modified12` 在 `0x10122cba` 保留原版 `cbz r1, #0x10122cce` 与调用方控制字节写回，其 `r1 == NULL` 与 `r1 != NULL` 两路行为由离线 ARM/Thumb 原生执行独立验证；实机侧留存的 9 张 14-bit 无损压缩 NEF（3 张 1/8000s BIAS + 3 张 5s DARK + 3 张 1/8000s FLAT）共 **220,487,040 个存储像素**经固定哈希 C++ 解码器与 LibRaw 逐像素比对**差异为 0**（证明正常静态采集与无损编码有效，但不将该 9 张留存文件等同于 `r1 == NULL` 分支的实机运行时覆盖证明）。
2. **暗场旧最近同色 8 邻域抑制保持解除，黑位附近未见零码截断**：在冻结的 112 个基准热像素点（`baseline112.json`，采用**最近同色 8 邻域核**，其中绿色核包含跨 `G1/G2` 的 `(±1,±1)` 对角点）上，原厂暗场为 `112/112` 命中 `中心 - 最近同色8邻域最大值 ∈ {0, 8, ..., 56}`，而 `Modified12` 三张 5s 暗场（`4970/4971/4972`）均为 **`0/112` 命中**、`111/112` 超出 `+56 DN`（中位差值 `11,387.0 ~ 12,388.0 DN`）。9 张样本有效区（`[8:4032, 8:6056]`）与完整存储区 `0 ADU` 像素计数均为 **0**，偏置/暗场存在 `<1008 DN` 码值分布（此系本批存储码值统计观察，不单独证明物理负向读出噪声完好无损、全局暗电流线性度或极弱星点测光保真）。
3. **同信号量级下旧红通道数字缩放缺码梳齿（`0.2276 cycles/DN`）大幅消退**：
   - 在 `0..16383` 统一 16,384 档直方图精确频率 `f = 0.2276 cycles/DN` 上，红通道 DFT 幅度组均值由 `Modified10` 的 **6989.36** 降至 `Modified12` 的 **680.33**（**下降 90.27%**，与 `Modified11` 的 `710.23` 处于同一量级），且本次 `Modified12` 平场中心净 `G1`（`3041.1 ~ 3497.4 DN`）与 `Modified10`（`3043.9 ~ 3609.5 DN`）处于同一曝光区间；
   - 平场中心净信号比 `R/G1` 组均值为 **0.8727**（`Modified11` 为 `0.8654`，`Modified10` 为 `1.0189`），相机记录的 `Auto1` 红通道白平衡系数为 `1.2871 ~ 1.2910`（`Modified10` 为 `1.5391`）。上述指标支持前端红通道数字乘数回落的定量判断，但在缺乏中性色标与标准预览对照前，不将其单独表述为色彩还原或“异常泛红消除”的定性验收。
4. **必须如实陈述的未闭环项与样本观察记录**：
   - **残余直方图周期谱峰仍在（来源未定）**：中心 400×400 红通道直方图在 `f = 0.17163 cycles/DN`（`4975/4976`，近似 `6/35 = 0.17143`）及 `f = 0.25732 cycles/DN`（`4978`，近似 `9/35 = 0.25714`）仍有显著峰值（主峰/频带中位数为 `13.17 ~ 16.51`），蓝/绿通道亦存在各自谱峰。中心 2000×2000 窗口局部可见 `12, 12, 11` 下凹间隔片段，但全窗口自动提取的全部局部下凹平均间距分别为 `9.70`、`10.27`、`9.90 DN` 且混有其他间距，因此仅记为**约 `35/3 DN` 候选周期族残余谱峰（物理或固件来源未定）**，不归因为特定传感器列 ADC DNL，更不能宣称直方图梳齿完全消失。
   - **径向与二维环状颜色结构尚未彻底消除**：在 `r ∈ [0.15, 0.90]` 统计区间内，`Modified12` 三张平场平均剖面的未滤波径向峰谷差为 `R/G = 1.5830 pp`、`B/G = 1.4130 pp`，`σ=6`（96 像素）局部高通残差峰谷差为 `R/G = 0.2228 pp`、`B/G = 0.1583 pp`（与 `Modified10` 局部残差相关系数 `r_RG = 0.9334`、`r_BG = 0.8969`）。平场混合了镜头光学、发光板与机内剩余固定链路，**“消除同心彩圈”目标尚未达成最终验收**。
   - **序号缺口与 `Z61_4969.NEF` 暗场相关亮点尾端**：样本目录在 `Z61_4972.NEF`（`MechanicalShutterCount = 401771`）与 `Z61_4975/4976/4978.NEF`（`401774 / 401775 / 401777`）之间缺少 `4973、4974、4977` 三个序号对应文件，**缺失原因未知（需拍摄记录确认）**，既不据此推定做过人工筛片，也不推定发生过或未发生过机身异常。此外第三张偏置场 `Z61_4969.NEF` 在有效区有 `189` 个像素 `> 2000 DN`（完整存储区为 `190` 个，多出的 1 点位于有效区外边框 `(y=4038, x=3137)`），其坐标与紧随其后的 5s 暗场 `4970` 高值点重合，记为**暗场相关亮点尾端**（单组样本不足以鉴定温升或曝光间隔等具体物理成因）。
