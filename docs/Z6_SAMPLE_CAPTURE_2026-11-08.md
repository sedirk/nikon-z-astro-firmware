# 下一轮：Z6 原版固件基线样本

2026-11-09 更新：用户已提供 NAS 85mm 星空／平场、另一机身旧暗场，并新拍同机身三张 1/8000 秒 bias 与两张 5 秒 dark。已完成[真实样本分析](REAL_NEF_BASELINE_2026-11-09.md)，下面九张清单保留作后续按需补样参考，不表示当前仍无样本或要求重拍。未来重点补同机身、同条件的其他曝光级与温度记录；候选仍分别验收。

这批照片用于测原版文件的暗信号、黑位和空间台阶。使用相机当前原版固件；记录实际版本。本项目的候选仍是实验包，本批样本无需安装候选。

## 统一设置

- 初代 Z6，FX 全尺寸、14 位、未压缩 NEF，M 档，固定 ISO 800（也可用常用天文 ISO，但整组保持一致并记录）。Z6 支持 12／14 位及未压缩 NEF，见[尼康官方规格](https://imaging.nikon.com/imaging/lineup/mirrorless/z_6/)。
- 长时间曝光降噪关闭；高 ISO 降噪、动态 D-Lighting、暗角控制设为关闭，记录能设置的项目。保留完整拍摄设置，不把菜单关闭本身当成 RAW 校正关闭证据。
- 固定同一快门模式，第一组建议普通机械快门。记录是否静音、镜头／望远镜／转接环、机身固件、室温、拍摄顺序和各曝光时间。
- 同一组保持光路、焦距、光圈和照明稳定；让相机温度尽量平稳。暗场要可靠遮光，不依赖软件把画面变黑。

## 第一批拍 9 张即可

| 类型 | 数量 | 拍法 | 用途 |
| --- | --- | --- | --- |
| 偏置 | 2 | 遮光，相机可选的短曝光，例如 1/8000 秒 | 基线黑位、读出分布 |
| 短暗场 | 2 | 同样遮光，1 秒 | 短曝光暗信号与重复噪声 |
| 长暗场 | 2 | 同样遮光，60 秒 | 曝光增长、低端裁切、热像素与邻域 |
| 平场 | 3 | 同一均匀光源／平场板、同一光路，分别取较暗、中等、较亮三档，只改曝光 | 查看空间颜色结构是否随信号级变化 |

平场用均匀漫射光，避免有纹理的显示屏、闪烁光源和明显渐变天空；各档都不要饱和。相机直方图来自预览，只作粗略参考，收到后会按 NEF 真实码值检查。若曝光过短导致光源条纹，调暗光源并延长曝光。三张平场应保留相同焦距、光圈、对焦和相机方向。

如果方便，每档平场各补一张更利于平均噪声；已有明显彩圈的天文亮场也可额外提供。第一批不要求重新拍一整套天文工程。

## 交付

把直接从存储卡复制的原始 NEF 和简短记录一起打包。不要转换为 DNG、另存或经过 RAW 处理软件导出；文件可以保留相机原名，用记录说明各张类型。

建议记录内容：

```text
机型 / 固件版本：
镜头或望远镜 / 转接环 / 焦距 / 光圈：
ISO / 位深 / 压缩 / FX 全尺寸：
快门模式 / 长曝降噪 / 高 ISO 降噪 / 暗角控制：
室温 / 拍摄顺序 / 机身是否已长时间通电：
文件名 → 偏置、1 秒暗场、60 秒暗场、平场暗/中/亮：
```

首轮报告会分别给出文件完整性、黑位与码值单位、暗场统计和空间结构。原版的九张样本可以建立诊断基线；候选的真实效果仍需后续同条件对照。不同真实曝光之间含随机噪声，不以“逐像素完全相同”作为相机拍摄的验收要求。
