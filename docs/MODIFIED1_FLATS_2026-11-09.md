# 候选固件首次平场：重复出现宽环状颜色结构，优先区分光源与校正

日期：2026-11-09。本轮输入为 `samples/11.9_modified1/Z61_4864.NEF`、`Z61_4865.NEF`。用户当前优先验证彩圈；本轮只读分析真实 NEF，没有继续改固件或刷机。

## 2. 实际观察

### 宽环状起伏：两帧重复，继续追踪

R/G 中心周围有宽的环状下降／回升，同时右上与左侧存在强烈不对称；B/G 也有宽的环形颜色分布和外侧渐降。16、32、64 像素浮点分箱均保留这些大尺度结构。

以图像几何中心作圆环均值，在半幅高半径的 0.15–0.90 范围内：

| 描述性量 | 4864 | 4865 |
| --- | ---: | ---: |
| R/G 径向最高－最低 | 1.437 个百分点 | 1.483 个百分点 |
| B/G 径向最高－最低 | 1.435 个百分点 | 1.461 个百分点 |

这一区间是观察初图后选择的探索范围，不是预先注册的检测。它表示总颜色起伏，**不是固件彩圈幅度**，也没有扣除镜头、屏幕和膜的影响。两帧的该段剖面相关系数 R/G 为 0.998、B/G 为 0.997；径向平均和大尺度渐变本身能使相关性很高，不把它换算成原因判断或置信度。

八个方位单独剖面显示明显的方向差异。当前视觉上突出的特征是宽渐变／宽环，没有提取出一组可归因于固件的细密阶梯边界。几何中心仅是分析参考，不假定它等于机身校正中心；也没有以此推导“彩圈已经不存在”的检测上限。

### 边缘条带：与宽环分开记录

4865 上缘出现很强的斜向窄带，4864 下缘亦有带状结构；两帧之差突出这些边缘。各自中心归一后的 G 差图，第 1 百分位约 −44%，说明局部亮度变化可达数十个百分点。它和用户观察到的屏幕/PWM 条带相符；本轮没有测量屏幕频率或将每个边缘变化都唯一归因于 PWM。

中心圆内 G 差值的第 5–95 百分位跨度仍约 5.66 个百分点，提示除了边缘窄带，照明分布也有变化。R/G、B/G 的除法能抵消一部分共同亮度变化，但不是可靠的屏幕条带消除算法。

### 黑位与分析方法控制

- 块内始终使用 float64 均值，避免低信号整数中位数产生假的环状台阶。
- 主图仅扣元数据 1008；对照使用此前候选 4857–4859 三张 bias 的均值。上述内圈内，切换 bias 处理造成的比例差绝对值第 95 百分位约 R/G 0.05%、B/G 0.07%，小于宽起伏。该检查不把三张 bias 当成无噪声校准真值。
- 保留 CFA 分相位位置对齐前后结果，以及常数黑位 1004/1012 的敏感性检查。
- 保留 48/96/192 像素三种平滑背景尺度，以及 32/64 像素分箱对照。局部高通像素主要包含随机波动；单个统计相关系数不作圈形检测。
- 64 个 CFA 块均值（2 帧 × 8 个位置 × 4 相位）用原 RAW 的独立逐项整数求和复算，全部一致。
- 行列分量扣除仅作为有损的干扰诊断数组保存，未用它判定彩圈消失；它也可能一起消去真环的部分分量。

## 3. 对当前补丁的判断

此前实拍已经支持三指令候选绕过一类曝光相关亮点／邻域抑制。当前候选未叠加四路负偏移、0x720 或空间参数表的修改。本轮两张平场新增的是**真实保存 NEF 的颜色结构基线**，不把暗场的成功扩大成消圈成功。

目前观察到的宽环，既不等于已经锁定硬编码校正，也不等于可以全部归咎于屏幕。需要继续保留两条解释：光源／光学形成的宽色彩分布；机内颜色空间校正及其量化结构。不要用另一机身的旧 NAS 平场或 Z85S 画面对本候选计算改善百分比。

## 4. 下一批最省事的取样

保持当前候选，先把屏幕干扰降下来，再安排同机身原版对照。1/8000 秒把屏幕变化冻结得很明显；延长曝光有助于平均周期变化，实际能否压住条带以 RAW 为准，不保证某个快门值一定无条纹。

1. 如继续用当前平板，可另起固定 **ISO 100、f/8** 的诊断组，先试 **1/30 秒**。按本次曝光粗估，这和目前 RAW 亮度接近，同时曝光显著延长。固定光圈、焦点、机位、平板亮度和距离，再试 1/15、1/8 秒，各 3 张；每档检查不过曝，若过曝就缩短曝光。这里是供试拍的起点，不是保证正确曝光的处方。
2. 这是一组新的固定光学条件；不要把 f/8 与已有 f/1.8 的差别算成固件效果。低 ISO 用于更容易显露量化台阶；实际天文工作 ISO 1600 仍需另外验收。
3. 相机不动，将平板在原平面旋转 180°，选一档重复 2–3 张。随光源一起变化的结构支持光源成分；不动的结构仍可能来自镜头、径向屏幕特性或机内校正，不能仅凭“不动”归因固件。
4. 有合适的漫射自然光或稳定连续光源后，再拍固定镜头／光圈的多档曝光。光照稳定后，若安排一次回到原版，用相同布置重拍，才形成候选／原版的直接消圈对照。

低 ISO、固定光圈、多快门、浮点 bias 扣除后检查 R/G 和 B/G，参考 [Mark Shelley 的原始 Z6 测试](https://www.markshelley.co.uk/Astronomy/NikonConcentricRings/nikon_hardcoded_correction.html)（本轮重新查阅，页面标注最后更新 2023-09-12）。该来源描述的是其原版相机测试，不是本候选的测试结果。
