# 平场约束下的空间控制定位与静态暗角中性化实验副本

日期：2026-11-09，Asia/Shanghai；初代 Nikon Z6 C3.80。接续[两张平场实拍分析](MODIFIED1_FLATS_2026-11-09.md)和[modified1 暗场实拍](MODIFIED1_REAL_NEF_2026-11-09.md)。目标保持：保留暗电流相关信号、关闭静态 NEF 写入前的 RAW 校正、消除彩圈。

**本轮已经把实际平场中的空间系数接到原厂处理函数与控制条件，并制成一个独立的 257 项暗角曲线中性化实验副本。它保留已安装的邻域关闭修改，相对 modified1 新增 6 个代码字节及 2 个 CRC 字节。离线原厂代码检查通过；该副本仍为 LAB 阶段，真实消圈效果由下一次同条件 NEF 对照验收。**

这轮没有刷写相机，没有覆盖现有 `01_TEST/EG162080.BIN`。原升级包、解包原模块、既有审查文件及两张源 NEF 均保留。原平场分析目录被冻结，本轮证据另存于 raw-ring-controls-2026-11-09（`analysis/raw-ring-controls-2026-11-09`，本地归档未公开）。

## 1. 两张平场给出的实际约束

4864、4865 均为同一机身／唯卓仕 16/1.8、ISO 1600、f/1.8、1/8000 秒、14 位无损 NEF，暗角设置 Normal。用户报告光源为满亮度、贴类纸膜的三星 Tab S9+，有 PWM 条带。此前 RAW 分析已确认：R/G、B/G 有可重复的宽环状结构，边缘条带随帧变化，完整有效区无饱和。

中间半径区的宽变化约为 1.4 个百分点，其中 R/G 有明显不对称；这两个同曝光样本没有提供多信号级的环边移动证据。因此，本轮把它们作为通道、空间形状和状态约束，没有从宽环外观直接指定某个算法为根因。

本轮直接读取真实 NEFInfo，核对内部 CRC 与文件 SHA-256。两张的以下字段完全相同：

| 实际文件字段 | 4864 和 4865 的共同值 | 原厂关联 |
| --- | --- | --- |
| NEFInfo6 四系数 | `2122853, -1812904, 1751073, 0` | `owner+1014..1020`，257 项曲线支线 |
| NEFInfo6 强度 L／状态 | `275 / 1` | `owner+1024` 与状态导出 |
| NEFInfo7 六系数 | `142, -79, 0, -74, -6, 61` | 两组 17 项表的同源参数 |
| NEFInfo7 两个标志 | `+4=1, +5a=1` | 由空间参数导出函数写入 |

详见字段提取结果（`analysis/raw-ring-controls-2026-11-09/nef-fields/result.json`，本地归档未公开）。这说明本次电子镜头拍摄保存了非中性的参数记录，更新了此前无电子镜头模拟状态下的中性结论的适用范围。元数据记录的是参数与状态，物理像素作用仍单独验收。

两张 NEFInfo8 的两项有符号数分别为 `(-9349,19076)`、`(-9856,18737)`，分母字段均为 256。该块用途本轮未命名；两张的防抖元数据均为 Off，故没有把这两个数直接解释为防抖位移。

## 2. 两组 17 项表：实际系数与原厂代码逐字节对上

原厂执行链：

```text
普通源网格／缓存的六系数
 → 10196fe4：建立空间子上下文
 → 10197500 → 10197820：选择状态与坐标
 → 10197410 → 1019702a：生成两组 17 项表
 → 101975be：导出表与控制字段
 → 10198640 → 100b5716 → 100d5c86
 → bank+1200 / bank+1224

同源六系数 → 10197678 → owner+ff8..1013
 → 102899a0 → NEFInfo7
```

本轮把真实六系数放入明确标注的缓存夹具；另建普通路径的常数基项网格，使原厂插值器计算相同六系数。导出缩放索引取 0，它对应 ROM 比例 4096。**普通、缓存两条路径均生成与真实平场完全相同的 104 字节 NEFInfo7，包含全部字段与 CRC。** 两个 ISP bank 的结果一致。这验证了代码与文件字段的联系，不表示恢复了相机拍摄时完整的 RAM 或唯一的源网格。

该夹具生成的两张表为：

```text
A:  8  8  8  7  7  7  6  6  6  5  5  4  4  4  3  3  3
B: -5 -5 -5 -5 -5 -4 -4 -4 -4 -3 -3 -3 -2 -2 -2 -1 -1
```

这是原厂参数运算的输出，尚未把表索引当成传感器半径，也未把数值解释成真实像素增益／位移。没有用这两张曲线拟合平场后宣布找到彩圈算法。

### 已验证的控制区别

共 22 组原厂执行对照，见完整记录（`analysis/raw-ring-controls-2026-11-09/spatial-replay/result.json`，本地归档未公开）。

| 输入条件 | 原厂结果 |
| --- | --- |
| 普通路径，源有效，`properties+45` 的 bit2=0，模式允许 | 产生非零六系数与两张表 |
| 普通路径，源有效，bit2=1 | 抑制／活动标志为 1／0，坐标归零，六系数与两表归零 |
| 普通路径，数字模式 7 或 18 | 本模块落到相同中性分支；模式的其他用途不在此表中推断 |
| 缓存标志 `[0,1]`，数字模式改为 7 | 仍生成原来的非零表，缓存分支不采用该普通模式门控 |
| 缓存标志只从 `[0,1]` 改为 `[1,1]` | 控制字和标签标志改变，原六系数与表仍保留 |
| 缓存标志 `[1,0]` | 原厂中性函数 `101973d4` 写零表，坐标／六系数也归零 |
| 源缺失，或缓存 `[0,0]`，坐标非零 | 两表为零，但坐标常数保留；夹具坐标 `(19,-23)` 导出系数 `(304,0,0,-368,0,0)` |

关闭用例预先填入非零旧表，实际观察到原厂写零覆盖，而非跳过写入后读到初始零。变化位于 `bank+700/+704`、两表及适用时的坐标字 `+730`；四负偏移 `+710/+714`、`+720` 和 RAW 输入／输出地址保持一致。

**工程取舍：两组 17 项表暂不并入新副本。** `properties+96` 除空间模块外，还在 `10171ff4..10172050` 选择主参数的缓存／普通来源；全局强制它会扩展修改范围。后续应在空间模块自己的静态入口设计控制，并分别验收坐标、缓存和像素效果。

## 3. 机身固定标定：新增一条完整的记录到寄存器路径

继续沿 ID `0x38` 标定资源追踪，得到：

```text
*(c18fa954+14) + 49a70 + group*816 + category*204
 → 1011e58c：按上下文选择 204 字节记录
 → 10122c20：更新 c29a3754 的部分字段
 → 参数包 c29a34c0+34
 → 100bccd0 → 100d82c2 → 1010b21c
 → 前端寄存器 20068718..200687d4
```

`group` 有 0–6 七组，每组四个记录。上下文 `+84!=0` 会选组 0；模式 2 选类别 3。普通类别由 `s16(ctx+14)` 和 `ctx+18` 的 2 倍／6 倍阈值选择，分母字段为 -1 时也选类别 3。这里保留原始字段名称，没有把这一比值强行命名为曝光时间或温度。

驱动的六组起点是 `2006871c / 738 / 754 / 770 / 78c / 7a8`，每组写七个 32 位配置字，加上公共字段共 48 次写入。**204 字节记录只负责第 1、2、4、5 组（从 0 编号）的主体；第 0、3 组由 `1011e616` 等另一支线填入。** 各组的控制字节也由多个生产者填写。

33 组选择／上传实验均通过，人工非零记录实际经过原厂代码。单独改变记录 `+8` 一个值，最终只改变 `20068738` 一个配置字。原有第 0、3 组的预填非零值完整保留并上传。详见固定记录实验（`analysis/raw-ring-controls-2026-11-09/front-fixed-record/result.json`，本地归档未公开）。

这条路径的模式与临时标志选择其他标定记录，没有得到统一的关闭条件。实验中的标定值均为人工夹具，真实机身 ID 0x38 内容仍需取得。该块的硬件处理名称、相对于 RAW 取样的位置及是否引入环纹继续追踪；不清空机身标定，也不把跳过部分写入当作关闭。

### 两张平场的 1/8000 秒会改变排查优先级

此前[144 项前端表研究](RAW_BODY_FRONT_2026-11-08.md)已经验证：某生成分支在数值 `t > 10*den` 且另一个门控允许时计算非中性表，在较慢快门条件产生常数表。以旧实验的标准分母 192 作换算，1/8000 秒对应约 `192*log2(8000)=2489.4`，位于阈值 1920 以上。因此，应把该短曝光分支重新纳入本次平场的候选，而不能直接套用长曝光暗场的排除顺序。

这是根据曝光条件作的推断；实机是否选中计算记录、是否走旧表复用仍需跟踪。延长平板曝光有助于同时观察条带与短曝光处理的变化，变化来源需要分别判别。

## 4. 新实验副本：只增加静态 257 项曲线中性化

本轮选择这个分支作为下一项独立实验，是因为实际文件已有非零系数和 L，原厂中性函数、静态入口与表上传路径都明确，而且可以保留现有暗场成果做单变量比较。它是彩圈原因候选之一；共同通道增益、颜色结构与量化效应的具体关系仍由实际 RAW 验收。

修改位于专用静态曲线属性构造器 `100c289e`，主调用为 `100c29c6 → 101004c0 → 1017235a → 101a1066 → 101a0f70 → 101a1240`。

| 地址 | 原指令 | 新指令／目的 |
| --- | --- | --- |
| `100c28b2` | `strb.w r0,[r4,#62]` | `strb.w sb,[r4,#62]`；sb 已为 0，让曲线生成器使用本地中性标志 |
| `100c28c8` | `strb.w sb,[r4,#63]` | `strb.w r0,[r4,#63]`；缓存调用原分支中 r0 是非零请求值，将中性标志置非零 |
| `100c2964` | `ldrb.w r0,[r0,#25f]` | `mov.w r0,#1`；普通调用明确置中性标志 |

调用者的普通／缓存分支保持原样。特别测试了缓存请求的辅助对象指针为空，仍走原来的缓存构造分支，没有因生成器选择字段改变而误入需要辅助对象的普通构造分支。

`101a1240` 原厂代码把曲线全部 257 项填为 1024，清零四系数和强度 L；后续仍调用原厂打包与配置驱动。这里的“中性化”描述该支线的参数效果，主处理使能字仍可保持开启值。它没有实施整条 ISP 的硬件旁路，也不是全部 RAW 校正关闭成果。

文件与配方：

- [版本绑定的完整配方](../patches/z6-c380-still-vignette-neutral-lab.json)：保留 modified1 三个邻域修改，再加本轮三个位置。
- LAB 模块说明（`analysis/raw-ring-controls-2026-11-09/lab-modules/README.txt`，本地归档未公开）与构建清单（`analysis/raw-ring-controls-2026-11-09/lab-modules/build.json`，本地归档未公开）。
- 模块 SHA-256：`6790186e7e088ae7c504677be052aecdbf3868616207bfda5606b36d37149038`，33,502,842 字节。
- 相对原版：16 个代码字节及 2 个 CRC 字节改变。相对已安装 modified1：6 个代码字节及 2 个 CRC 字节改变。三个新指令均不更新条件标志，不新增跳转或调用。
- 构建器验证原文件 SHA、每处原字节、CRC 与逐字节恢复；审查器另验证精确恢复到 modified1。

## 6. 失败记录、可复现性与下一步

命令 12 的首轮脚本把 `VECTOR+0` 辅助输出误接为打包属性，并混淆了 17 项表输入的位置；断言在上传检查时停止。按原厂 `10171fae`、`10171dbc` 的指针赋值修正为 `VECTOR+8` 和 `TARG+4`，同时按原厂双槽选择分别检查实际写入槽，命令 14 全部通过。失败脚本、日志、部分结果均保留于 `lab-native`，最终有效结果是 `lab-native-v2`；固件副本本身在修正测试脚本前后没有改变。

本轮正式命令与输出（`analysis/raw-ring-controls-2026-11-09/commands`，本地归档未公开）逐项记录；原文件、样本、上一轮冻结证据与进度文档备份由 [finalize_raw_ring_controls.py](../tools/fw/finalize_raw_ring_controls.py) 核对。新目录的 `evidence-index.json` 保存最终文件哈希与脚本快照。没有提交 Git。

接下来优先：

1. 对这个确切 LAB 文件完成新一轮升级入口与副作用审查，再准备明确的实机比较文件；现有刷机包保持独立。
2. 在当前 modified1 下建立较慢快门、固定光圈、多信号级的平场基线。若另拍 ISO 100、f/8，按新组处理；新副本复拍同组，逐通道比较环边、台阶和量化规律。1/8000 秒旧组继续作为短曝光基线。
3. 若 257 项中性化改变实际环纹，沿该支线细化；若只改变整体明暗或软件解释，则据真实 NEF 把重心转到两组 17 项表和固定前端标定。保持一次改变一个支线，避免效果混淆。

当前明确分层：**实机事实**是 modified1 的强暗信号保留与两张平场的实际结构；**本轮验证事实**是参数来源、原厂控制行为、离线修改边界；**待验收假设**是新曲线中性化对最终 NEF 彩圈的真实影响及机身固定标定的具体角色。
