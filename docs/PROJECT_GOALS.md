# 项目工程目标与验收准则 (Project Engineering Goals & Acceptance Criteria)

> 🌐 **语言 / Language**: **简体中文** · 🏠 [返回项目主页](../README.md) | **[文档索引](README.md)** | **[更新日志 (Changelog)](CHANGELOG.md)**

## 1. 核心目标定义

本项目面向初代 **Nikon Z6（基础固件版本 C3.80）** 天文与深空延时摄影场景，核心工程诉求如下：

> 在保留传感器真实物理暗电流、解除机内侵入式空间滤波与非线性暗角/通道增益校正（消除同心彩圈并还原改机原生量子效率）的同时，提供与日常摄影无冲突的菜单无感切换、原生 30"~600" 扩展慢门及曝光后纯等待间隔拍摄能力。

---

## 2. 六大工程目标拆解

1. **全链路处理边界识别**：识别静态 NEF 写入前全部相关处理阶段，严格区分 CPU 软件配置、前端/后端 ISP 算子、硬件位打包编码器与仅作用于 JPEG/预览的管线。
2. **暗信号与黑电平统计完整性**：保留暗电流及其自然泊松/高斯统计涨落，杜绝黑电平下方硬截断归零（Zero-clipping）；正偏置（`BlackLevel = 1008`）维持原厂可解释定标。
3. **解除吃星与热像素空间钳制**：定位并旁路 $3\times 3$ 同色邻域热像素抑制（`max8 + 8k`），保护微弱单像素星点 Airy 斑并确保主暗场（Master Dark）与亮场逐像素可扣减。
4. **消除硬编码同心彩圈与人为通道预放大**：清除前端 ISP 2D 多项式暗角调制与四通道非单位 Q12 数字乘数（归零至 `1.0000×` 单位增益），消除直方图 `0.2276 cyc/DN` 周期性缺码梳齿，还原天文改机红光动态范围。
5. **全位深与全压缩格式等价直通**：在 12-bit / 14-bit、无损压缩 / 未压缩及全快门档位（含 `>= 1s` 长曝光与 `60"~600"` 扩展慢门）下均输出无损线性紧致打包 NEF，无缓冲区越界或内嵌预览污染。
6. **确定性可复现与安全可回退**：绑定官方 C3.80 输入哈希，公开完整补丁配方与零第三方密钥表构建器，校验和与反向回退字节恒等经独立验证，支持随时刷回官方原厂固件。

## 3. 验收标准矩阵

| 目标维度 | 必须具备的客观证据 | 当前正式版（`Modified23` / `v3.80-modified23`）闭环状态 |
| :--- | :--- | :--- |
| **保留暗信号** | 同温/同 ISO 下检查偏置与长曝暗场分布、零码计数及读出噪声对称性 | **已闭环**：全幅有效区 `0 ADU` 像元计数恒为 `0`，`< 1008 DN` 负向涨落完整保留（偏置中央 68% $\sigma = 3.54\text{ DN}$，`5s` 无损与未压缩暗场均为 $4.24\text{ DN}$） |
| **关闭空间过滤** | 冻结 112 个基准热像素在长曝暗场中的 `max8 + 8k` 邻域钳位命中率检验 | **已闭环**：`5s` 无损压缩、`5s` 未压缩与 `60s` 扩展慢门未压缩实拍暗场均为 **`0 / 112`（0% 钳位）**（[evidence/m23_audit_metrics.json](evidence/m23_audit_metrics.json)） |
| **消除硬编码彩圈与通道预放大** | 同曝光平场直方图 FFT 梳状谱峰与中心 `R/G1` 原生通道比对照 | **已闭环**：`0.2276 cyc/DN` 谱峰下降约 $13.5\times$（带内峰值下降约 $9.8\sim 13.4\times$），中心 `R/G1` 由机内加权的 `1.0101` 回归原生 `0.8997`（[01_ASTRO_RAW_AND_CONCENTRIC_RINGS.md](01_ASTRO_RAW_AND_CONCENTRIC_RINGS.md)） |
| **全格式数据完整性** | 无损压缩与未压缩 NEF 独立解码器 vs `LibRaw` 全幅逐像素比对、零预览重叠 | **已闭环**：全库 **130 张**真机 NEF 解码零误差；`5s` / `60s` 未压缩 `packed-14`（`42,920,960` B）共 `1.47 亿` 像素与 `LibRaw 0.22.2` 逐像素 `0` 差异、预览重叠 `0`（[MODIFIED23_UNCOMPRESSED_ASTRO_RAW_FIX_2026-11-18.md](MODIFIED23_UNCOMPRESSED_ASTRO_RAW_FIX_2026-11-18.md)） |
| **UI 解耦与长曝自动化** | 色空间开关与 RAW 菜单互不干扰、sRGB 命名保持、600s 慢门与曝光后间隔准确运行 | **已闭环**：`PID 0x0526` 菜单切换 + `PID 0x130A = 0` 锁定标准 `Z61_` / `sRGB`，M 档 `60"~600"` 连拍与曝光后间隔实机验证通过（[03](03_UI_SWITCH_AND_COLOR_SPACE_ARCHITECTURE.md)、[04](04_EXTENDED_SHUTTER_AND_INTERVAL_TIMER.md)） |
| **可复现与诚实交付** | 纯标准库可复现确定性构建包；未经真机实拍闭环的候选改动绝不混入正式版 | **已闭环**：`tools/build_modified23.py` 确定性构建 `105` 处补丁并附原厂回退包；`hardware_pixels_verified = true` |
