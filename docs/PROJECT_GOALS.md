## 用户确定的需求

用户原始要求是：

> 我想用尼康z6进行天文摄影，我需要保留暗电流，禁止一切机内raw矫正(避免出现彩圈)。

研究对象为初代 Nikon Z6，当前输入固件为 C3.80。最终目标不是新增快门声音或菜单展示，而是获得适合天文校准、保留所需原始暗信号且不被机内处理引入彩圈的 RAW。

## 工程目标

以下是落实用户目标的工作拆分，不代表用户已同意缩减“禁止一切机内 RAW 矫正”的范围。

1. 识别静态 NEF 写入前全部相关处理，区分 CPU 软件、ISP 配置、传感器内部处理、文件编码和只影响预览的处理。
2. 保留暗信号及其统计分布，排除不可逆黑位裁切；分别调查偏置、暗信号扣减和逐机标定。
3. 识别并关闭热像素抑制和 RAW 空间过滤，验证对星点与暗场校准的影响。
4. 优先定位造成彩圈的硬编码空间校正，分别调查通道缩放和镜头相关校正。
5. 保留完整位深，使用无损或未压缩 NEF；仅选择无损压缩不算完成“原始 RAW”目标。
6. 为确认可控的处理设计版本绑定、可复现、可分别开关的修改，记录输入哈希、原字节、替换字节、校验和及效果。

正偏置与物理暗电流不是同一概念。不要把“关闭矫正”直接实现为黑电平归零或清空全部标定数据；是否保留必要偏置，应以防止信号裁切和最终数据可解释性判断。如果某项处理无法关闭，需要明确说明限制，不能把部分成功宣称为最终完成。
