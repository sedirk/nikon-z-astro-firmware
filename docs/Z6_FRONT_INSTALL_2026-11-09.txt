先做什么
1. 按当前记录，相机运行 modified3。先按 FLAT_COMPARE.txt 拍新的 A 组，固定相机、平板、对焦和光源。旧平场留作参考。

3. 将 ZIP 完整解压。四个固件目录是独立选择；只选一个文件复制到卡根目录。

文件选择
01_TEST_MODIFIED4\EG162080.BIN：本次前端开关测试。

先校验解压包（本机 PowerShell）：

复制、校验、人工更新
1. 将 01_TEST_MODIFIED4 内的 EG162080.BIN 复制到卡根目录，保持文件名。根目录仅保留这一份固件，排除其它 BIN/BI/LAB 和 BIN.bak。
2. 确认自己的卡盘符，把下面 E:\ 换成该盘符，再核对卡上的实际文件：
& "<repo-root>\work\re_env\Scripts\python.exe" "<repo-root>\outputs\Z6-C380-front-bit11-reviewed-2026-11-09\verify.py" --card-root "E:\" --mode test
3. 确认 "ok": true、mode=test、SHA 相符，安全弹出卡。
4. 插卡，进入相机设置菜单的固件版本/更新，按相机提示操作。若文件未识别或提示不匹配，先记录提示，停止本次更新；不要改成其它机型的文件名。
5. 更新中保持供电，完成后按相机提示重启。记录所用哈希、更新完成时间和提示；菜单 3.80 本身无法区分版本。
6. 先试拍一张普通单张 NEF，确认取景、保存、回放及放大正常，然后拍 B 平场和暗场。若出现异常，保留文件和现象记录；菜单可用时按下方回退。

回退
优先选 02_BACK_TO_MODIFIED3。仅在相机仍可正常进入更新菜单时，将选定回退文件替换卡根目录候选，用同一校验器核对：
--mode modified3 / --mode modified1 / --mode stock，必须与所选文件一致。
再按相同人工更新步骤操作。回退文件不是自动救砖机制；实际回退是否成功需另记。
