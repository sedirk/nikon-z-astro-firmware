# 专题报告 02：解除吃星现象与保留真实物理暗电流

## 1. 现象分析：吃星与暗场校准失效 (The Star Eater Problem)

在消费级数码相机中，为了在普通摄影中获得更“纯净”的高感画面，机内图像处理器通常会对暗部信号执行侵入式的噪点抑制算法：
1. **暗电流与热噪点被钳位**：
   传感器上具有较高暗电流的孤立感光单元（热像素，Hot Pixels）会被强制替换为其同色邻近像素的中值或上限；
2. **微弱单像素星点被吞噬**：
   在天文摄影中，星光在感光元件上聚焦出的高能量微弱单像素或双像素 Airy 斑，其空间频域特征与热噪点高度相似，导致弱星被算法直接抹除或亮度被腰斩；
3. **主暗场无法匹配扣除**：
   后期制作 Master Dark（主暗场）扣除亮场时，由于热像素已被机内算法随机非线性替换，暗场扣除无法与亮场一一对齐，反而会在深空图像中留下密密麻麻的黑色“冷斑”（Pockmarks）。

---

## 2. 算法逆向与跳过逻辑

在原厂固件 `0x100C2654` 处，代码对输入 RAW 像素执行了一组空间邻域卷积评估：

### 2.1 原厂邻域检测模型
原厂算法提取当前像元 $P_0$ 及其周围同色 $3\times 3$ 邻域（间隔 2 个像元以匹配同色拜耳点）的 8 个邻近值：
$$M_8 = \max(\{P_1, P_2, \dots, P_8\})$$
若当前中心像素值 $P_0$ 显著偏离邻域且：
$$P_0 > M_8 + \Delta$$
原厂逻辑将触发平滑抑制，将 $P_0$ 截断或插值替换为 $M_8 + 8 \times k$（其中 $k \in [0, 7]$）。

### 2.2 固件补丁机制
在 `Modified13` 及后续版本中，我们通过在 `0x100C2654`、`0x100C267C`、`0x100C2690` 注入 Thumb 跳转跳板：
- 当检测到当前处于天文直通模式时，直接绕过这组邻域中值与上限截断计算，将原始 DMA 像素值直通下游编码器；
- 保持原厂 14-bit 黑电平基准（`BlackLevel = 1008`）的完整泊松散粒噪声涨落，绝不对 $<1008\text{ DN}$ 的负向读出噪声做截断归零（Zero-clipping）。

## 3. 证据与量化核实 (112 个基准热像素检验)

为了科学检验暗电流保留效果，我们在传感器中心区域冻结了 **112 个特征热像素坐标点**（基准坐标清单已随附归档于 [docs/evidence/baseline112.json](evidence/baseline112.json)），在 5 秒暗场中进行多固件跨版本回归检验：

| 固件版本 | 112 基准点命中旧钳制比例 | 强暗信号像素保留率 | 帧差读出噪声 (中央68% / 未裁剪) | 零码像元 (0 ADU) 计数 |
| :--- | :--- | :--- | :--- | :--- |
| **官方原厂 C3.80** | **112 / 112 (100% 钳位)** | 邻域抑制严重截断（$0 / 112$ 超出 $+56\text{ DN}$） | $3.54\text{ DN} / 4.61\text{ DN}$ | 0 个零码 |
| **Modified1 ~ Modified4** | $0 / 112$ (0% 钳位) | $111\sim 112 / 112$ 超出 $+56\text{ DN}$ | $3.54\text{ DN} / 4.59\text{ DN}$ | 0 个零码（自然泊松分布） |
| **Modified12 / Modified13**| $0 / 112$ (0% 钳位) | $111\sim 112 / 112$ 超出 $+56\text{ DN}$（M13 为 $112/112$） | $3.54\text{ DN} / 4.10\sim 4.11\text{ DN}$ | 0 个零码 |
| **Modified22 (最新版，直通模式)** | **0 / 95 (0% 钳位，洁净行区)*** | **95 / 95 (100%) 超出 $+56\text{ DN}$** | **$3.54\text{ DN} / 4.11\text{ DN}$** | **0 个零码** |

*\*注：`Modified22` 保持与 `Modified13` 完全相同的 13 处 ISP 直通钩子；本批 M22 5s 暗场实拍采用「未压缩」模式触发了底部 `3633..4000` 行预览覆盖，故在洁净行区 `y+2 < 3633` 的 95 个冻结点上测得 `0/95` 命中钳位。日常 `>= 1s` 长曝光请固定选用「无损压缩（Lossless compressed）」（详见 [MODIFIED22_REAL_NEF_AUDIT_2026-11-17.md](MODIFIED22_REAL_NEF_AUDIT_2026-11-17.md)）。*

### 3.1 结论
- 解除了机内对孤立热像素与暗电流的侵入式非线性邻域抑制，避免了微弱单像素星点被算法误当噪点抹除；
- 读出噪声统计维持自然连续的高斯/泊松涨落，未对黑电平下方实施硬截断；
- 在使用无损压缩拍摄 Master Dark 进行暗场校准时，热像素位置与亮场保持一致，显著改善深空堆叠伪影。
