## 1. 实机依据和本轮目标

[modified3 实拍](MODIFIED3_REAL_NEF_2026-11-09.md)已确认：真实 NEFInfo7 active=0，非中性空间系数归零，旧暗角中性参数保持；两版各三张 5 秒 dark 在冻结 112 点均为 0/112 命中旧邻域抑制指纹，111 个强点保持。另一个弱点在 modified2 已弱，不算 modified3 新问题。

屏幕平场的宽颜色起伏没有整体减弱：R/G 为 1.256→1.380 个百分点，B/G 为 1.431→1.350 个百分点。布置或对焦可能移动，且光源有 PWM 条带。该结果让工作从已有保存参数反馈的后端曲线/空间表，继续向前端和固定标定的控制条件推进；宽光学颜色结构与细密量化环分别验收。

本次新增变量是前端寄存器 `0x20068500` 的 bit11。其原厂显式关闭条件已定位，具体硬件处理名称和真机该位原来的状态仍待识别；不直接给它冠以“彩圈校正”名称。

## 2. 真正写入者已经找到

以下地址和偏移均为十六进制。两个 QEMU 写入监视实验捕获了真实请求对象的生产和复制，随后以原厂指令作有界回放：

```text
配置区 c20aa7c8 + 3d2（本次运行地址 c20aab9a）
  → 配置 getter 101cb734
  → 1013f0b2 生产五字节小块；1013f0e6 写第 4 字节
  → 调用点 10140fbc 的目标 c236f620 + 255
  → 实际请求对象 c236f620 + 259 = c236f879
  → 请求处理 101e3088，101e30ac..ba 复制 260 字节
     BLX 10170ec8；实际 ARM memcpy 写入 PC 10170ee4
  → 静态前端源 c236d378 + 259 = c236d5d1
  → 100f64b4 → static input +45
  → 10179962 → context c18fa844 +5d
  → 1011db02 选择 CAL+55c0+index*128 的 policy
  → 1011d850..1011d866 覆盖 control[2]
  → c29a3520[2] → packet c29a34c0[0]
  → 100bccd0 → 100d8248 → 1010adf6
  → 20068500 bit11
```

其中复制长度 `0x260` 为十进制 608 字节。生产器依次读取配置 `3dc、3df、11b、29f、3d2`；前四项用不同指纹值检验，确认没有把相邻配置串到目标字节。两次监视的完整事件和内存保存在 `native-owner-watch/`、`native-request-watch/`。

控制语义：值 **1 强制开启该项，2 强制关闭，其它值读取选中 CAL 记录的 u16+4**。原厂 ROM 默认配置 `114732e0+3d2` 为 0，由 `101cb7a6` 初始化；该值表达走标定策略，不能把“默认 0”理解成硬件一定关闭。模拟器实际配置为 0，合成零 CAL 使寄存器该位原本也为 0；真实机身持久配置和标定内容另行取证。

工程菜单绑定 `103cbd80..9e` 在配置 `3d2/3d3` 与控件 `1ee2` 之间建立了关系，但尚未恢复可靠的可读处理名称。新增控制只改静态读取点，不改全局配置，以免牵连其它配置消费者。

本轮也排除了两处容易混接的同偏移对象：`1013fa20` 操作后端 owner `c3b568d0`；`1036b0a2` 本次写入的是 `c201d7bc`。它们都不是上述请求对象。两个静态调用点 `101e216c`、`101e43c0` 则确实将 `c236d378` 交给 `100f6290`。

## 3. 候选的确切修改与范围

100f64b4  90 f8 59 02  ldrb.w r0, [r0, #0x259]
       → 4f f0 02 00  mov.w  r0, #2

**第一次整体验收失败及处理：** 22 号命令把静态输入多比较了 4 字节（原生清零/初始化块实际为 `0x4c`），并要求所有辅助缓冲及 context 尾部一致。补充同一固件重跑后，确认这些位置存在同版本运行间变化：辅助地址槽在 m3、m4 内均可变，context+a0/a4 在相同 m4 内也不同。最终保留全部快照，限定输入比较到原生 0x4c 块；以尾部匹配的运行比较完整 0xe4 context，仅+5d 变化；RAW 参数前 0x28 字节（含主目的指针）相同。context+a0/a4 的写入原因未追完，不据此宣称全内存确定性或全模式覆盖。失败日志没有删除，候选字节没有为通过检查而调整。

安装流程仍擦写约 **43.25 MiB** 主区域 `10020000..12960000`；几字节的补丁也要经过完整更新流程。测试包内回退文件用于菜单仍可工作的相机；当前没有经过实机验证的不开机恢复流程。真实断电、卡故障、擦写时序及实际回退不由离线调度替代验收。

## 5. 收敛到实机验收

1. 当前 modified3 拍新的 A 组，保留相机/平板位置、距离、角度、手动焦点和光源画面。旧 A 只作背景参考。慢快门、多信号级优先，1/8000 秒另列。
2. 校验包与卡上文件后，只安装一次 modified4；记录实际更新完成及文件哈希。版本文字和 NEFInfo6/7 都无法独自识别这次新增修改。
3. 普通 NEF 保存/回放正常后拍相同条件 B，再拍 ISO1600 的 5 秒暗场三张，回归冻结 112 点。只用原始 NEF 码值判定环结构及局部暗信号效果。
4. 若环结构有一致变化，再做必要的回退复现、不同曝光/镜头验证；若无变化，记录该前端位在本条件下的结果，继续查真实 policy 状态及其它前端表，不堆叠多个未知位。

假设仍为：该项前端处理可能影响剩余 RAW 校正。它可能在真机已关闭，也可能与彩圈无关。当前硬证据是控制来源、原厂关闭路径、最小修改及离线升级兼容性；**消圈成效由新 A/B 实拍独立决定**。
